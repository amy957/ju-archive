### P-13 多标签并发写盘 — 通过

**首次判定有误，已更正。** 初判依据是「进程数 = 2 且窗口标题不同（`JU 笔记` / `JU`）」，
据此认定单实例失效。复测时用 `EnumWindows` + `GetClassName` 区分窗口类名，结果：

```
21308 | class=Window Class | title=JU        ← 唯一应用窗口（Tauri/WebView2）
21308 | class=Tao Thread Event Target | title=   ← 内部事件窗口
30572 | class=#32770       | title=JU 笔记   ← 标准 Win32 对话框类（MessageBox）
```

`#32770` 是 `singleton::note("JU 笔记已在运行，已请求切换到已打开的窗口。")` 弹出的
**原生 MessageBox**，不是第二个文档窗口。

- **断言 A 成立** ✓：第二实例走 `Ok(None)` 分支 → 弹提示 + `SetEvent` 请求聚焦 → 退出；
  全程只有一个文档窗口（class `Window Class`）
- 进程计数会短暂为 2，是因为该 MessageBox 为模态、等待用户点确定，进程尚未退出
- **断言 B**：不适用（单实例设计成立）
- **断言 C** ✓：数据目录无 `ju_store.*.json.tmp` 残留
- 局限：「聚焦已有实例」的可见效果被模态提示框遮挡，未独立取证（需在提示框出现前抓前台句柄）
