## 3. P1 · 实现精确到字符的 Overlay

改动文件（仅 2 个产品文件，未动 `JU.ui()` / `boot.ts` / 富文本核心）：

### 3.1 `src/ui/xselect.ts`

- 新增 `#ju-xsel-overlay` 容器（懒创建、`position:fixed / top:0 / left:0 / 100vw×100vh / pointer-events:none / z-index:9999`）。
- `paintOverlay()`：对模型每块 `xselRangeInHost()` 换算 `Range` → `Range.getClientRects()` → **每个字符矩形**一个
  `<div class="ju-xsel-block">`，`left/top/width/height` 用矩形原值（两位小数）。
- `nativeIntervalIn()` + `subtractRange()`：渲染前**扣掉原生选区已绘制的区间**，避免「原生绿 + overlay 绿」双层叠深。
  after 实测：原生 rect `356..428`、overlay 首块从 `428` 起，首尾相接、无重叠。
- `clearOverlay()`：`xselClear()` 与「模型为空」的 `selectionchange` 一律清空 overlay。
- `bindViewportRefresh()`：`scroll`（capture）/ `resize` / `selectionchange` 重算；新增 `document mousedown`（capture）兜底，
  作用域**收紧**为「`#content` 内、且不在 `.text` / `.row` 内」——右侧工具栏在正文面板之外，逐块套样式时模型不会被提前清空。
- `.ju-xsel` 类保留为**零绘制模型标记**（见第 7 节偏差说明）。

### 3.2 `src/style.css`（文件末尾 fix13 段）

```css
#ju-xsel-overlay{position:fixed;top:0;left:0;width:100vw;height:100vh;pointer-events:none;z-index:9999;display:none;margin:0;padding:0;border:0;background:transparent}
#ju-xsel-overlay .ju-xsel-block{position:absolute;background-color:color-mix(in srgb,var(--accent) 20%,transparent);border-radius:2px;pointer-events:none}
```

- `.text.ju-xsel` 零绘制（fix12 契约保持）；`.outline .row.sel / .row.multi-sel` 透明（fix12 作用域保持，侧边栏 / 日历行不受影响）。

### 3.3 由测试暴露并修复的真实缺陷（先取证后改源码）

`tests/v21-fix13-exact-selection.spec.ts`「点空白 ⇒ block 归零」首次运行 **失败**（实测残留 3 块）：
`#content` 内、`.outline` 之外/行之外的留白（大纲下方）按下时，`views/outline.ts` 的 wrap 与 row 两级 `mousedown` 都收不到，
模型残留 ⇒ overlay 不消失。修复为上述 `onDocMouseDown` 兜底（不改 outline.ts），复跑通过。

## 7. 偏差说明（取证驱动，非口头声称）

1. **`.ju-xsel` 类未移除**：任务书 P1 要求「不再给 `.text` 添加 `ju-xsel`」。实测该类是 fix7 / fix11 / fix12 三份既有 spec
   的**模型标记断言**所依赖的契约（直接移除需改动三份历史批次用例，违反「零漂移」与「不把新批次写进 fix1~fix12」）。
   处理：保留打标 + **维持 fix12 的零绘制**，视觉高亮 100% 由 overlay 承载；探针逐块复核 `.text.ju-xsel`
   `background-color=transparent`、`background-image=none`、`box-shadow=none`。
2. **`.row.sel / .row.multi-sel` 背景**：fix12 已在 `.outline` 作用域清零（这两类是焦点行标记而非选区高亮），本批保持不动；
   探针逐行复核为透明，侧边栏 / 日历行的同名类不受影响。
3. **点空白取消选中**：由新增的 `document mousedown`（capture）兜底补齐（第 3.3 节），未改 `views/outline.ts`。
