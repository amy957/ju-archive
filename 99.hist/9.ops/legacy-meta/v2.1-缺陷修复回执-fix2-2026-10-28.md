## 八、偏差说明（与任务书字面不一致处，均已说明理由）

1. **`.cal-checkbox` 的 `margin`**：任务书示例写 `margin: 0`；本批保留 `margin: 5px 0 0 0`。
   理由：原基线为 `margin-top:5px`，改 0 会让勾选框整体上移 5px 与正文错位（布局漂移），与「零漂移」冲突。
   其余（`appearance:none`、14×14、`border-radius:50%`、`border:1.5px solid var(--cb-color,#9aa0a6)`、
   `background:transparent`、`pointer-events:auto`）与任务书一致。
2. **CSS 未新增第二套 `.cal-checkbox` 规则**：把基线 498–500 行的三条 `.cal-node .cal-checkbox*` 规则**原地替换**为
   fix2 版本（任务书 P1-5「覆盖或合并，不要产生两套冲突样式」），`--cb-color` 变量名沿用。
3. **未单独产出 `2.项目日志/m07-fix2-build-2026-10-28.txt`**：本批唯一一次构建是 `build-all`，
   其日志 `2.项目日志/m07-fix2-build-all-2026-10-28.txt` 内已含 `[3/5] Web 构建 vite build` 段（含产物指纹）。
   为免二次 `vite build` 造成哈希漂移（可能破坏 §五 四路一致），不再单独重跑 vite。
4. **`toggleDone` 未改**：H3 在日历调用点闭合（`saveUI` + `invalidateCalIndex` + `forceRender`），
   避免影响大纲/其他视图既有的「增量补丁不全量失效」优化。
