### 2.1 H1 —— 新建标签即被挂到当前文档（P1 缺陷）

```
-- 步骤 3（C）：新建标签后的关联性取证 --
  当前文档 cur={"id":"v3bma4fg2mu","text":"F5DOCC #F5TAGC",
                "tags":["F5NEWTAGC","F5NEWTAGA","F5NEWTAGB"],
                "manual":["F5NEWTAGC","F5NEWTAGA","F5NEWTAGB"]}
  全库 tags/_manualTags 命中新建标签 = 3 条（v3bma4fg2mu × 3，inTags=true, inManual=true）
  state._tags（全局标签注册表，fix4 产物无此字段 → null）= null
```

根因（fix4 源码 `promptNewTag`）：创建标签时直接把 `t` 写入**当前选中节点**的 `n.tags` 与 `n._manualTags`。

### 2.2 H2 —— 标签列表顺序冻结，不跟随「排序切换」（P2 缺陷）

`#sortBtn`（`index.html:47`，`title="排序切换"`，回调 `src/app/session.ts:1081-1089`）循环
`name→type→created→updated→star`（`ui.filesSort`），实测：

| 点击 | 模式（toast） | 文档列表前 3 | 标签列表前 5 |
| --- | --- | --- | --- |
| 0 | name | 欢迎使用 JU / F5DOCA #F5TAGB / F5DOCB #F5TAGA | F5TAGA / F5TAGB / F5TAGC / F5NEWTAGC / F5NEWTAGA |
| 1 | type | 同上 | **完全相同（冻结）** |
| 2 | created | F5DOCC #F5TAGC / F5DOCA / F5DOCB | **完全相同（冻结）** |
| 3 | updated | F5DOCC / F5DOCA / F5DOCB | **完全相同（冻结）** |
| 4 | star | F5DOCC / F5DOCA / F5DOCB | **完全相同（冻结）** |

- 文档顺序去重数 = 2（按钮生效）；**标签成员顺序去重数 = 1（完全不跟随）**；
- 各模式「标签顺序 == 文档位次顺序」= **false**（5/5 全不匹配）。

根因：`renderSubTags` 硬编码 `.sort((a,b)=>b[1]-a[1])`（计数降序），与 `deps.sortDocs(..., ui.filesSort)` 无关。

## 5. Playwright 结果

- 新增 `tests/v21-fix5-tag-sort-and-create.spec.ts`（4 条）：
  1. 新建标签不自动关联任何文档（只进 `state._tags`，count=0 仍可见）；

  4. 排序状态在数据更新后实时生效（切到 `updated` 后新建带新标签的文档，标签列表立刻把它排到首位，且状态不被清）。
