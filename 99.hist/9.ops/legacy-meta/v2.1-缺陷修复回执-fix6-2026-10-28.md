| 块 | `.prio-badge` font-size | 徽章 w×h | 块高占比 | 图标 span 字号 | 两图标间距 |

根因（`src/style.css`，fix5 交付版）：

- `style.css:406` `.cal-tg-ev{font-size:max(12px,.8em)}` ⇒ 块内 em 基准 **12px**；
- `style.css:858` `.cal-tg-ev.has-prio>.prio-badge{font-size:.72em}` ⇒ **0.72 × 12 = 8.64px**；
- `style.css:847` `.prio-badge{display:inline-flex;gap:2px}` ⇒ 两图标间距仅 2px；
- `style.css:855` `.prio-badge[data-prio]>.prio-ok{font-size:11px}` ⇒ OK 图标与两个字母图标不同口径且不随块缩放；
- `style.css:857` `.cal-tg-ev.has-prio{align-items:flex-start}` ⇒ 图标顶对齐，与正文基线不一致。

即：**43px 的事件块里只画了 8.64px 的图标（占块高 20%），周视图优先级几乎不可见**（缺陷成立）。

## 3. P1 修复（`src/style.css`，纯 CSS 类）

修改点：`src/style.css` 第 856 行区块「周视图时间网格事件块」整段重写（原 4 行 → 带取证注释的 17 行）：

```css
.cal-tg-ev.has-prio{display:flex;align-items:center}
.cal-tg-ev.has-prio>.prio-badge{font-size:max(16px,1.34em);line-height:1;gap:5px;padding:0;margin:0 6px 0 0;flex:none;align-items:center}
.cal-tg-ev.has-prio>.prio-badge>.prio-important,
.cal-tg-ev.has-prio>.prio-badge>.prio-urgent{display:inline-block;font-size:1em;line-height:1}
.cal-tg-ev.has-prio>.prio-badge>.prio-ok{display:inline-block;font-size:.88em;line-height:1}
.cal-tg-ev.has-prio>.evtx{flex:1 1 auto;min-width:0}
```

设计依据（逐条对应任务书 P1 要求）：

| 任务书要求 | 实现 |
| --- | --- |
| 图标放大到适合块高（如 16 / 18px） | `max(16px,1.34em)`：默认 0.72em→**1.34em = 16.08px**；取 16px 而非 18px，因半小时块内容高仅 17.4px，18px 会贴边越界 |
| 字号缩放时同步放大 | 用 `em` 兜底（`.cal-tg-ev` 字号随 `--font-size` 放大时徽章同比放大），`max()` 保证任何缩放下不低于 16px |
| 两图标间距增大 | `gap: 2px → 5px`（实测 spanGap 2 → 5） |
| 两行块（如 80px）不越界 | 同一字号 + `align-items:center` 居中；86px 块实测 top/bottomOffset 各 ≈35px |
| 图标 `line-height:1`、垂直对齐 | 徽章与两个图标 span 均 `line-height:1`、`display:inline-block` |
| 不在 JS 写死尺寸 | `calendar.ts` 未改一行：`priorityBadges()` 本就只产 class，尺寸全在 CSS |
| 文字被挤压 / 换行 → flex 单行 | 块 `align-items:flex-start → center`；`.evtx{flex:1 1 auto;min-width:0}` 保留，正文单行省略 |

**零漂移校验**：仅动 `src/style.css` 一个区块 + 新增 1 个 spec 文件；未触碰 `boot.ts` / 富文本核心 / `xselect.ts` / `JU.ui()` 对象 / 标签数据；月视图 `.cal-item>.prio-badge`（`style.css:861`）与大纲视图 `p1~p5` 旧样式未改。
