# 多选与全选规范（v2.1-dev）

来源：《JU软件设计框架规范》1.3 状态管理模型、7.3 UI 状态、8.1 commit 唯一入口、10.1 事件委托与直接绑定、十六、UI 交互增强规范（v2.1-dev）16.2；《细节要求描述文档》2.2/2.4/2.6 v2.1-dev 新增。

## 1. 选择模型

```text
ui.selection = {
  type,      // 视图类型：outline / database / sidebar
  ids,       // 选中的节点 id 集合
  anchorId,  // Shift 范围选择锚点
  mode       // single / additive / range / all
}
```

- 仅内存，刷新清空，不持久化，不入撤销栈
- 禁止将 ui.selection 写入 state.nodes 或持久化存储

## 2. 交互

| 操作 | 行为 |
| --- | --- |
| Ctrl/Cmd 点击 | 切换单个选中 |
| Shift 点击 | 范围选择（anchorId 起止区间） |
| Ctrl+A | 全选当前视图模型 |

## 3. 视图覆盖

| 视图 | 多选/全选 | 批量操作 |
| --- | --- | --- |
| 侧栏树（2.2） | Ctrl/Cmd、Shift、Ctrl+A | 批量拖拽移动、批量缩进/反缩进、批量删除 |
| 大纲（2.4） | 支持，跨屏选择 | 移动、缩进、反缩进、删除、标记完成、加标签 |
| 数据库（2.6） | 表格行、看板卡片、画廊卡片 | 改状态、移动、删除、加标签 |

## 4. 批量操作与 commit

- 批量操作合并为一次 commit
- 逆操作记录每个节点的原 parent、原 index、原顺序
- 一次撤销恢复全部

## 5. 虚拟滚动兼容

- 全选基于当前视图模型，不基于 DOM
- 虚拟滚动开启时全选不漏选
- 保留“关闭虚拟滚动”降级开关（与 P1c 真虚拟滚动回归时验证跨屏选择）
