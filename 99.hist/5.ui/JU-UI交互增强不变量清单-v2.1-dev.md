# JU-UI 交互增强不变量清单（v2.1-dev）

- 版本：v2.1-dev
- 关联规范：《JU软件设计框架规范》1.3 状态管理模型、7.3 UI 状态、8.1 commit 唯一入口、10.1 事件委托与直接绑定、15 维护规范、十六、UI 交互增强规范（v2.1-dev）
- 同步日期：2026-10-13
- 说明：v2.1-dev 新增 UI 交互增强（拖拽/调整大小、多选/全选、折叠按钮与沉浸模式）期间必须恒成立的不变量；作为行为对拍与回归基线。

## 不变量清单

| 编号 | 不变量 | 来源 |
| --- | --- | --- |
| I01 | ui.selection 仅内存，刷新清空，不持久化，不入撤销栈 | 1.3 / 16.2 |
| I02 | 禁止将 ui.selection 写入 state.nodes 或持久化存储 | 7.3 |
| I03 | 多选/全选后的批量操作必须合并为一次 commit；逆操作记录每个节点的原 parent、原 index、原顺序 | 8.1 / 16.2 |
| I04 | 全选必须基于当前视图模型，不基于 DOM，确保虚拟滚动下不漏选 | 10.1 / 16.2 |
| I05 | 纯 UI 调整（面板宽高、浮窗位置尺寸、分区高度顺序、沉浸模式切换）使用 light:true 或 persistOnly:true，不入撤销栈 | 8.1 / 16.1 |
| I06 | 业务拖拽（文档节点移动、日历事项改时间、数据库行改状态）使用 snapshot:true，一次操作一次 commit，入撤销栈 | 8.1 / 16.1 |
| I07 | 拖拽/调整大小监听必须注册 cleanup，并在 pagehide 兜底清理，防止内存泄漏 | 15 / 16.1 |
| I08 | 沉浸模式退出后恢复原折叠状态与面板宽度 | 16.3 |
| I09 | 新增 UI 状态必须加入 applyUIFields 与 _saveUINow | 15 |
| I10 | 新增 DOM 元素 id 必须全局唯一 | 15 |
| I11 | 修改 renderSidebar / renderMain / updateRightSidebar 必须回归：光标保持、多选状态、虚拟滚动、沉浸模式、打印隐藏非内容元素 | 15 |

## 验收口径

- 每次修改涉及本清单任一不变量时，必须对照 I01–I11 复核；
- 回归执行见《JU-UI交互增强回归清单-v2.1-dev.md》，验收见《JU-UI交互增强验收记录-v2.1-dev.md》。
- L9 影子层 / L10 持久层接缝在本形态不适用（ISSUE-014 · m07-vite 未迁移 L9，根因见 ADR-D01）：boot 不设 initL9Shadow / initL10Seam 端口，main 不注入。
