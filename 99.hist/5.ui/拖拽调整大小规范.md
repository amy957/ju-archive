# 拖拽调整大小规范（v2.1-dev）

来源：《JU软件设计框架规范》8.1 commit 唯一入口、10.1 事件委托与直接绑定、十六、UI 交互增强规范（v2.1-dev）16.1；《细节要求描述文档》2.1/2.4/2.5 v2.1-dev 新增。

## 1. 对象范围

### 1.1 可拖拽对象

- 可折叠分区（主侧边栏 / 检查器面板内）
- 浮窗
- 悬浮日历
- 文档模块（侧栏树节点、数据库行/卡片、画廊卡片）
- 日历事项（移动时间）

### 1.2 可调整大小对象

- 左右侧栏
- 检查器面板
- 浮窗
- 日历面板
- 分区高度

## 2. 事件协议

- 拖拽统一使用 pointerdown / pointermove / pointerup，配合 setPointerCapture
- 调整大小使用统一 resize 协议：pointerdown 记录起点 → pointermove 计算 delta → pointerup 提交
- 所有拖拽监听必须 pagehide 兜底清理，防止内存泄漏
- 新增拖拽/调整大小必须注册 cleanup，并在 pagehide 兜底清理

## 3. 提交规则

| 类型 | commit 参数 | 撤销栈 |
| --- | --- | --- |
| 纯 UI 调整（面板宽高、浮窗位置尺寸、分区高度顺序、沉浸模式切换） | light:true 或 persistOnly:true | 不入撤销栈 |
| 业务拖拽（文档节点移动、日历事项改时间、数据库行改状态） | snapshot:true | 入撤销栈 |

## 4. 拖拽三分法

- 上半区：插入之前
- 中区：成为子节点
- 下半区：插入之后

## 5. 持久化

- 浮窗位置与尺寸持久化到 UI 状态
- 可折叠分区折叠状态与分区尺寸持久化
- 日历面板与记事本列尺寸持久化

## 6. 回归要求

- 拖拽侧栏分区调整高度，刷新后保持
- 拖拽浮窗调整位置尺寸，刷新后保持
- 文档节点拖拽移动，撤销可恢复
- 日历事项拖拽改时间，撤销可恢复
- 修改渲染入口必须回归光标保持
