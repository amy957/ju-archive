# 沉浸模式与侧栏折叠按钮规范（v2.1-dev）

来源：《JU软件设计框架规范》1.2 布局模型、十六、UI 交互增强规范（v2.1-dev）16.3；《细节要求描述文档》2.1 v2.1-dev 新增。

## 1. 侧栏折叠按钮

- 左侧折叠按钮：固定在主内容区左下角
- 右侧折叠按钮：固定在主内容区右下角
- 中间“同时折叠”按钮：同时收起左右侧栏

## 2. 沉浸模式按钮

- 默认淡化（低可见度）
- 鼠标下移或键盘聚焦时显现
- 启用后：隐藏左右侧栏与检查器，仅保留主内容区

## 3. 状态与恢复

- 沉浸模式切换使用 light:true 或 persistOnly:true，不入撤销栈
- 沉浸模式退出后恢复原折叠状态与面板宽度
- 沉浸模式状态持久化到 UI 状态

## 4. 打印

- 打印时隐藏折叠按钮与沉浸模式按钮（非内容元素不进入打印输出）

## 5. 回归要求

- 沉浸模式按钮淡化与 hover 显现正常
- 同时折叠按钮同时收起左右侧栏
- 打印时隐藏折叠按钮与沉浸模式按钮
- 修改 renderSidebar / renderMain / updateRightSidebar 必须回归沉浸模式与打印隐藏
