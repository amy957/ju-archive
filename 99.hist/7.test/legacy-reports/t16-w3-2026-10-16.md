## 二、实现（全表扫描 → 增量计数）

### 2.1 计数载体与辅助（canonical L6 基础设施段）

新增 `state` 计数载体与辅助函数（植入 [`L6 基础设施`](../../6.P0-L3基线/v2.0-l3.html.html:2434) 段）：

```js
const _SIDECOUNTS=Symbol('_sidebarCounts');   /* Symbol 键 ⇒ 序列化不可见 */
function _sideCount(s,id){…}                  /* 单节点贡献（与 renderSidebar 原循环表达式逐字对齐） */
function _sideCountsFinalize(acc,s){…}        /* 由 dbRootId 派生 dbCount（= dbRoot.children.length） */
function _sideCountsRebuild(s){…}             /* 全表重建（initStore / merge 等整体替换后） */
function _sideCountsApply(base,from,to,ids){…}/* 增量：按「新贡献 − 旧贡献」修正 */
function _sideCountsGet/_Set(s,acc){…}        /* 读 / 写挂载 */
function _sideCountsEnsure(s){…}              /* 缺失兜底：重建挂载 */
```

计数对象形状 **`{starred, docCount, dbRootId, dbCount}`**：
- `starred` / `docCount`：与 `renderSidebar` 原全表循环表达式逐字等价（含 `!n._isFolder && !n._isDbRoot && !n._isCalRoot` 等谓词）；
- `dbRootId`：根子中 `_isDbRoot` 节点 id（供 `renderSubDb` 及 `dbCount` 派生）；
- `dbCount`：由 `dbRootId` 派生 `dbRoot.children.length`（与 `renderSidebar` 原式 `dbRoot?dbRoot.children.length:0` 等价）。

> **键选择（契约优先）**：计数对象以 **`Symbol('_sidebarCounts')`** 挂在 `state` 上。`JSON.stringify`（`getState()` 持久化 / [`encryptState`](../../6.P0-L3基线/v2.0-l3.html.html:1132) / [`saveAutoBackup`](../../6.P0-L3基线/v2.0-l3.html.html:18489)）与 `for..in`（[`collectModifiedPaths`](../../6.P0-L3基线/v2.0-l3.html.html:2245)）**均不可见** ⇒ **`juju.store.v31` 序列化形状、加密 payload 内容、历史 patch 形状零变更**（若用字符串键，[`copyPlain`](../../6.P0-L3基线/v2.0-l3.html.html:1217) 的 `Reflect.ownKeys` 会将其物化为可枚举键，污染序列化与 patch，违反数据契约红线）。

### 2.2 维护接缝（L6 收口 + 整体替换）

| 接缝 | 位置 | 处置 |
|---|---|---|
| `commit`（正常提交） | [`commit()`](../../6.P0-L3基线/v2.0-l3.html.html:4372)（L6 索引维护同址收口） | 以真实 patch 句柄 **`_l8Patch`**（外层 `_patch` 被内层同名声明遮蔽恒 `undefined`）取 `extractChangedIds` → `_sideCountsApply`；`__juInMerge` → 整体重建；无 patch（`'never'`）→ 继承基数 |
| `undo` | [`undo()`](../../6.P0-L3基线/v2.0-l3.html.html:4728) | 反向增量（from=post=`_preState` → to=pre=`state`） |
| `redo` | [`redo()`](../../6.P0-L3基线/v2.0-l3.html.html:4766) | 前向增量（from=pre → to=post） |
| `initStore` | [`initStore()`](../../6.P0-L3基线/v2.0-l3.html.html:2125) | 整体替换 → `_sideCountsRebuild` |
| `mergeRemoteState` | [`mergeRemoteState` finally](../../6.P0-L3基线/v2.0-l3.html.html:1907) | 就地改写 `state.nodes` → 整体重建 |

> **增量粒度**：仅「`starred` / `_isDbRoot` / `parent===root` 变更」的节点对三计数贡献非零增量；`dbRoot.children` 变更经 `nodes.<dbRootId>.children` 路径进入 `changedIds` ⇒ `dbRootId`/`dbCount` 同步刷新。

### 2.3 renderSidebar（读取口径，删除全表循环）

```js
const _sc=_sideCountsGet(state);            /* O(1) 读取 */
if(_sc){ starred=_sc.starred;docCount=_sc.docCount;dbRoot=_sc.dbRootId?N(_sc.dbRootId):null; }
else if(__l14On()){ __l14SideScanEnsure(); … }   /* 降级①：分片协同扫描 */
else{ … 原全表循环 … }                            /* 降级②：非优化分支（语义不变） */
```

- **主路径**：`state` 计数存在即直读，**不再遍历全表**。
- **降级兜底**：`state._sidebarCounts` 缺失 → `__l14On()` 走 `__l14SideScanEnsure()`；否则回退**原全表循环**（非优化分支零变更 · 红线守持）。

### 2.4 红线守持（降级 / 契约）

- **非优化分支保留**：`__l14On()=false` 时的全表循环、`_vsUserDisabled=true` / `IS_DESKTOP=false` 路径**逐字保留**；
- **数据契约零变更**：`state.nodes` 结构、`juju.store.v31` 序列化形状、加密 payload 字段名、历史 patch 形状均不变（Symbol 键不可见）；
- **公开 API 冻结**：`window.__juIndexShadow` / `window.__juPersistProbe` / `window.__juL9Shadow` / `window.__juL10D1` 方法名与返回形状零变更；
- **不新增 `<script>` 块**（9 块不变）。
