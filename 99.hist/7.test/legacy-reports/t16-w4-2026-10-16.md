## 一、动因与范围

- **动因**：落实《优化指令 · 指令 4》。大纲视图的标题高度同步原走「每次渲染 rAF 测量 + 无条件写入」，是渲染尾部的同步布局阻塞与样式失效来源；目标：**改为尺寸订阅（ResizeObserver）驱动，仅标题高度实际变化时刷新**，消除每渲染一次的强制同步布局与 rAF 幽灵节点读取。
- **范围**：仅 [`canonical`](../../6.P0-L3基线/v2.0-l3.html.html:1) + step9 镜像 + 登记 / 门禁口径 + 波报告 / 证据；**不新增纳编物**（登记方数保持 **43**）。

## 二、实现（rAF 测量 → ResizeObserver 订阅）

### 2.1 订阅载体与辅助（canonical · script_2 / `_syncOutlineHeaderH` 同址段）

新增 `_outlineHeaderRO` 载体与辅助函数（植入 [`_syncOutlineHeaderH`](../../6.P0-L3基线/v2.0-l3.html.html:7039) 紧邻段）：

```js
let _outlineHeaderRO=null;                     /* 标题高度订阅（替代每渲染 rAF 测量） */
function _setOutlineHeaderH(wrap,h){…}         /* 写入门槛：仅 --doc-header-h 实际变化才写入 */
function _observeOutlineHeader(wrap){…}        /* 挂载后订阅 .doc-header；缺 RO 时回退即时测量 */
function _disconnectOutlineHeaderRO(){…}       /* 视图切换 / 重渲染前断开旧订阅 */
```

- `_setOutlineHeaderH`：`getPropertyValue('--doc-header-h')` 比对后再 `setProperty`（**同高不重写**）。
- `_observeOutlineHeader`：先断开旧 RO → 取 `wrap.querySelector('.doc-header')`；无标题则 `removeProperty` 并返回；`typeof ResizeObserver!=='function'` 时降级 `_syncOutlineHeaderH`；否则 `new ResizeObserver(...)` 观察 `.doc-header`，回调读 `h.offsetHeight` 经 `_setOutlineHeaderH` 写入。
- `_syncOutlineHeaderH`（[FIX-R7-1](../../6.P0-L3基线/v2.0-l3.html.html:7039) 保留）：改为收口到 `_setOutlineHeaderH`（「变化才写入」），保留为 **applyScale / 无 RO 降级**路径。

### 2.2 renderMain 接缝（挂载后订阅 · 顶部断开）

| 接缝 | 位置 | 处置 |
|---|---|---|
| 顶部断开 | [`renderMain()` 顶部](../../6.P0-L3基线/v2.0-l3.html.html:13492)（与 `oldGraph._cleanup` / `oldMM._cleanup` 同址） | `_disconnectOutlineHeaderRO();`（重渲染前断开旧标题 RO） |
| 挂载后订阅 | [`renderMain()` 大纲分支](../../6.P0-L3基线/v2.0-l3.html.html:13589)（`c.appendChild(el)` 之后） | `if(view===VIEW_KIND.OUTLINE){_observeOutlineHeader(el);requestAnimationFrame(()=>{if(el&&el._vs)_vsUpdate(el._vs);});}` —— **rAF 内不再调用 `_syncOutlineHeaderH`**（仅保留虚拟滚动 `_vsUpdate`） |

> **applyScale 兼容**：[`applyScale()`](../../6.P0-L3基线/v2.0-l3.html.html:5229) 仍调用 `_syncOutlineHeaderH(document.querySelector('.outline'))`（字号缩放为离散交互，非每渲染）；因写入改为「变化才写入」，与 RO 回调不产生重复样式失效。

### 2.3 红线守持（降级 / 契约）

- **非优化分支保留**：`typeof ResizeObserver!=='function'` 时回退 `_syncOutlineHeaderH` 即时测量；无 `.doc-header` 时移除属性（语义不变）。
- **数据契约零变更**：`_outlineHeaderRO` 为模块级变量 + 元素属性订阅，**不写入 state / 序列化 / 加密 payload / patch 形状**；
- **公开 API 冻结**：`window.__juIndexShadow` / `window.__juPersistProbe` / `window.__juL9Shadow` / `window.__juL10D1` 方法名与返回形状零变更；
- **不新增 `<script>` 块**（9 块不变）。
