## 二、实现内容（节点拖动 + 数据同步 · 结构与代码）

### 2.1 状态管理数据结构（拖动局部状态 · useRef 等价物）

拖动全程 **不写 `state`、不提交、不触发全局重渲染**；仅在闭包内维护一份局部可变状态（原生实现中「`useRef` 等价物」）：

```js
/* renderMindmap 闭包内 —— 拖动局部状态 */
let _mmDrag = null;    /* { id, startX, startY, origLeft, origTop, dragging, drop, exclude } */
let _mmHitPos = null;  /* rAF 内待处理的落点世界坐标 { x, y } */
const MM_CULL_N = 200; /* 节点数超阈值 → 命中测试 / 懒渲染视口裁剪（G-2） */
```

- `_mmDrag.id`：被拖节点；`exclude`：`_mmCollectDesc(id)` = **自身 + 子树**（杜绝成环）；
- `_mmDrag.drop`：当前落点目标节点 id（用于高亮与提交）；
- 数据同步的**唯一真源**仍是全局 `state`（`nodes[id].parent` + `parent.children[]`）——拖动结束后的层级变更经 [`commit()`](../../6.P0-L3基线/v2.0-l3.html.html:4149) 单次落库。

### 2.2 拖拽事件处理代码（自由拖动 + 落到节点改层级）

节点 `mousedown` → `>5px` 进入拖动；`mousemove` 仅改 `left/top` 并标记脏连线（单 rAF）；`mouseup` **单次提交**：

```js
d.addEventListener('mousedown', e => {
  if (d.classList.contains('editing')) { e.stopPropagation(); return; }
  e.stopPropagation();
  const startX = e.clientX, startY = e.clientY;
  const origLeft = parseFloat(d.style.left), origTop = parseFloat(d.style.top);
  const oldParent = (N(nd.id) || {}).parent || null;      /* 记录原父（增量补丁用） */
  const exclude = _mmCollectDesc(nd.id);                  /* 排除自身 + 子树，防环 */
  _mmDrag = { id: nd.id, startX, startY, origLeft, origTop, dragging: false, drop: null, exclude };
  const onMM = ev => {
    if (!_mmDrag || _mmDrag.id !== nd.id) return;
    if (!_mmDrag.dragging) {
      if (Math.abs(ev.clientX - startX) < 5 && Math.abs(ev.clientY - startY) < 5) return;
      _mmDrag.dragging = true; d.classList.add('dragging'); d.style.cursor = 'grabbing';
      document.body.style.userSelect = 'none';              /* 拖动视觉反馈：半透明 .dragging */
    }
    ev.preventDefault();
    const dx = (ev.clientX - startX) / _mmScale, dy = (ev.clientY - startY) / _mmScale;
    d.style.left = (origLeft + dx) + 'px'; d.style.top = (origTop + dy) + 'px';
    _mmMark(nd.id);                                         /* 仅重绘该节点关联连线（单 rAF 节流） */
    const cr = canvas.getBoundingClientRect();
    _mmQueueHit((ev.clientX - cr.left) / _mmScale, (ev.clientY - cr.top) / _mmScale); /* 落点检测并入 rAF */
  };
  const onMU = () => {
    document.removeEventListener('mousemove', onMM);
    document.removeEventListener('mouseup', onMU);
    const dg = _mmDrag; _mmDrag = null;
    if (!dg || !dg.dragging) return;
    d.classList.remove('dragging'); d.style.cursor = 'text'; document.body.style.userSelect = '';
    if (dg.drop) { const pe = _mmEls.get(dg.drop); if (pe) pe.classList.remove('drop-target'); }
    d._mmDragged = true;                                    /* 抑制拖动后误触发的 click 进入编辑 */
    const toNode = dg.drop ? N(dg.drop) : null;
    const canNest = dg.drop && dg.drop !== oldParent && toNode && !toNode._isCalRoot && !toNode._isDbRoot;
    if (canNest) {
      /* 拖到另一节点 → 改变层级：单次提交；changedIds = {被移动节点, 原父, 新父}（G-5） */
      commit(s => {
        const n = s.nodes[nd.id], to = s.nodes[dg.drop];
        if (!n || !to) return;
        const from = s.nodes[n.parent];
        if (from) { const i = from.children.indexOf(nd.id); if (i >= 0) from.children.splice(i, 1); }
        to.children.push(nd.id); n.parent = dg.drop; n.updatedAt = _nowSeq();
        /* 清除被移动节点及其子树手动坐标 → 自动并入新父布局（G-1 自动重排） */
        const clear = x => { const m = s.nodes[x]; if (!m) return; delete m.mmX; delete m.mmY; (m.children || []).forEach(clear); };
        clear(nd.id);
      }, { snapshot: true });
      wrap._mmChangedIds = _mmChangedIds(nd.id, oldParent, dg.drop);
      forceRender();
      return;
    }
    /* 自由拖动：仅持久化 canvas 绝对坐标（视图态，不入撤销历史） */
    const nx = parseFloat(d.style.left), ny = parseFloat(d.style.top);
    commit(s => { const nn = s.nodes[nd.id]; if (nn) { nn.mmX = Math.round(nx); nn.mmY = Math.round(ny); nn.updatedAt = _nowSeq(); } }, { snapshot: false, persistOnly: true });
    wrap._mmChangedIds = _mmChangedIds(nd.id, null, null);
  };
  document.addEventListener('mousemove', onMM);
  document.addEventListener('mouseup', onMU);
});
```

**视觉反馈（CSS）**：`.mm-node.dragging`（拖动中半透明 + 置顶 + 阴影）；`.mm-node.drop-target`（落点目标高亮描边）+ `.mm-node.drop-target::after`（「设为子节点」**落点指示器**）。

### 2.3 落点检测（并入单 rAF · 视口裁剪）

```js
function _mmHit(px, py) {                         /* px,py = canvas 世界坐标（已除 scale） */
  const ex = _mmDrag && _mmDrag.exclude;           /* 排除自身 + 子树 */
  const many = nodes.length > MM_CULL_N;           /* >200 → 视口裁剪 */
  for (const [id] of _mmEls) {
    if (ex && ex.has(id)) continue;
    const b = _mmBox(id); if (!b) continue;         /* 尺寸缓存；缺失时 measure */
    if (many && !_mmHitInView(b)) continue;         /* 屏外节点不参与命中 */
    if (px >= b.cx - b.hw && px <= b.cx + b.hw && py >= b.cy - b.hh && py <= b.cy + b.hh) return id;
  }
  return null;
}
function _mmQueueHit(x, y) { _mmHitPos = { x, y }; _mmSchedule(); } /* 合并进 rAF，避免每 move O(N) */
```

`_mmFlush()`（单 rAF）在完成脏连线重绘后，消费 `_mmHitPos` → `_mmSetDropTarget(_mmHit(...))`，仅在**落点变化**时切换高亮类（无命中变化 → 零 DOM 操作）。

### 2.4 更新树形结构并生成 `changedIds` 的伪代码（G-5）

```text
输入：movedId（被移动节点）、newParentId（落点目标）
前置：oldParentId = state.nodes[movedId].parent
校验：newParentId != movedId；newParentId 不在 movedId 子树内（exclude 保证）；非系统容器

commit(draft):
    from = draft.nodes[oldParentId]
    if from: from.children.remove(movedId)
    draft.nodes[newParentId].children.push(movedId)
    draft.nodes[movedId].parent = newParentId
    draft.nodes[movedId].updatedAt = seq()
    clearCoords(movedId 及其子树)          // 删除 mmX/mmY → 自动重新布局（G-1）

changedIds = { movedId, oldParentId, newParentId }   // 增量补丁：仅「被移动节点 + 原父 + 新父」
结果：commit 由 patch 路径（nodes.<moved>.parent / updatedAt、原/新父 children[]）自动派生
     等价 changedIds → 持久化层 / L6·L7 增量索引层仅重算这三个节点（无全局 O(n) 重建）。
```

- **自由拖动路径**：`changedIds = { movedId }`（仅视图坐标变更，`snapshot:false` 不入历史）。

### 2.5 连线（Edges）实时重绘思路

- **锚点**：沿用指令 10 的 [`juBorderAnchor()`](../../6.P0-L3基线/v2.0-l3.html.html:11915) 外边框盒最近交点（不连文字 / 中心）。
- **拖动中**：`_mmMark(movedId)` → 仅把 `movedId` 关联连线入 `_mmDirty` → 单 rAF 的 `_mmFlush()` 仅对这些连线重算 `d`（bezier）；**不重算全量连线**。
- **拖动结束（改层级）**：树结构变化 → `clearCoords` 令被移动子树回退自动布局 → `forceRender()` 一次结构性重排，新建连线骨架后首帧 rAF 按外边框锚点重绘。
- **视口裁剪**：`_mmDrawEdge(it, cull)` 以 `_mmInView` 跳过两端点均在可视区外（含余量）的连线。

### 2.6 防止全局重渲染的说明（G-2）

1. **拖动期间零提交**：`mousemove` 仅改 `style.left/top`（合成器属性）+ 写 `_mmDrag`/`_mmHitPos` -> 单 `requestAnimationFrame` 合并；**不调用 `commit`、不调用 `forceRender`**。
2. **提交仅在 `mouseup`**：自由拖动 1 次 `commit({persistOnly:true})`；改层级 1 次 `commit({snapshot:true})` + 1 次结构性 `forceRender()`（层级变更本质需重排，与 `outlineBatchMove` 同范式）。
3. **增量边界**：无论拖动中（`{movedId}`）还是改层级后（`{movedId, 原父, 新父}`），受影响集合恒为 3 个节点以内。
4. **命中测试节流**：`_mmHit` 仅在 rAF 内执行一次；节点 >200 时叠加视口裁剪；`.mm-wrap.mm-many .mm-node{content-visibility:auto}` 对屏外节点懒渲染。
5. **`getBoundingClientRect`**：仅在拖动 move 中对 canvas 取一次（换算世界坐标）；节点尺寸测量走 `offset*` 尺寸缓存，绝不在高频回调内穿透测量。
6. **无结构性 HTML 变更**：不新增 `<script>` 块（**inline script 块数 = 9 不变**）；不新增纳编物。
