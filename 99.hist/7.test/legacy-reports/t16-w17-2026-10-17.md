## 一、动因与范围

- **动因**：主库结构损坏（如 nodes 形状异常 / 根指针不可修复）时，把可恢复的自动备份降级为默认空态，属于**恢复链断裂**。修复目标是「备份优先于复位」。
- **范围**：仅 [`canonical`](../../6.P0-L3基线/v2.0-l3.html.html:1) + step9 镜像 + 登记 / 门禁口径 + N 层用例 / 证据 / 波报告；**不新增纳编物**（登记方数保持 **43**）。

## 二、实现

| 接缝 | 改前 | 改后 |
|---|---|---|
| 迁移失败处理 | `migrateOrFallback(st)` → `return r||defaultState();` | 新增 [`migrateOrBackup(st)`](../../6.P0-L3基线/v2.0-l3.html.html:18856)：成功即返回；失败时先 `loadAutoBackup()`，备份 `state` 迁移成功则**从备份恢复**；否则仍 `defaultState()` |
| boot 主库路径 | `initial=migrateOrFallback(...)` ×5 | `initial=migrateOrBackup(...)` ×5（桌面加密解锁 / 桌面快照 / 桌面遗留迁移 / 浏览器加密解锁 / 浏览器主库） |
| 空库备份分支 | `initial=ab?migrateOrFallback(ab.state):defaultState();` | **原样保留**（备份本身失败时复位，避免二次读取同一坏备份） |
| 加密态 | — | `ui.encrypted && ui.encKey` 时**不读取明文自动备份**，维持默认态回退（既有加密语义 / 不引入明文残留） |

改动后函数（canonical 现行 18852–18872）：

```js
/* L16-W17 · 指令 8（Defect-E）：迁移失败时优先回退自动备份，避免直接复位默认态遮蔽有效备份。
   备份存在且迁移成功则从备份恢复；否则（备份缺失 / 备份亦损坏）仍回退 defaultState。
   加密态（ui.encrypted && ui.encKey）不读取明文自动备份（保持既有加密语义 / 不引入明文残留）。 */
function migrateOrBackup(st){
  const r=migrateStateObject(st);
  if(r)return r;
  try{
    if(!(ui&&ui.encrypted&&ui.encKey)){
      const ab=loadAutoBackup();
      if(ab&&ab.state){
        const rb=migrateStateObject(ab.state);
        if(rb){
          try{toast('主库损坏，已自动恢复到最近一次备份');}catch(e){}
          return rb;
        }
      }
    }
  }catch(e){}
  if(st){try{toast('检测到数据损坏且无法自动修复，已重置为默认状态');}catch(e){}}
  return defaultState();
}
```

> **决策记录 L16-W17-D1（明文备份恢复的加密态守卫）**：指令语义为「迁移失败 → 尝试备份 → 成功则恢复」。本波在**加密态**（`ui.encrypted && ui.encKey`）保持原行为（提示后复位默认态），理由：① 加密模式的自动备份写 `__autobackup__` 加密快照，`localStorage[AUTO_BACKUP_KEY]` 中的明文备份可能是**启用加密前的历史残留**，读取并恢复会引入明文回填；② 加密快照的救援需要用户密钥上下文，属独立恢复路径（登记 **OP-L16W17-1**）。非加密路径（浏览器 / 桌面明文）完整实现指令语义。
> **降级 / 契约**：`state.nodes` 结构、`juju.store.v31` 序列化形状、加密 payload 字段名零变更；公开 API（`window.__juIndexShadow` / `window.__juPersistProbe` / `window.__juL9Shadow` / `window.__juL10D1`）零变更；`IS_DESKTOP=false` 的既有空库 / 不可解析 JSON 分支行为不变；**不新增 `<script>` 块**（9 块不变）。
