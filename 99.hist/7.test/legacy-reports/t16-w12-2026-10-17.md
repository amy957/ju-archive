## 一、动因与范围

- **动因**：Defect-B 属树结构完整性缺陷 —— `children` 出现 `null` 洞后，下游 `state.nodes[cid]` 取到 `undefined`，渲染 / 索引 / 侧栏计数沿 `null` 传播；且洞会被后续补丁反复捕获、逐次固化（越用越多）。
- **范围**：仅 [`canonical`](../../6.P0-L3基线/v2.0-l3.html.html:1) + step9 镜像 + 登记 / 门禁口径 + N 层用例 / 证据 / 波报告；**不新增纳编物**（登记方数保持 **43**）。

## 二、实现（applyPatch 返回前 children 审计）

| 接缝 | 改前 | 改后 |
|---|---|---|
| [`applyPatch`](../../6.P0-L3基线/v2.0-l3.html.html:2424) 返回前 | 仅 `try{if(typeof repairTreeConsistency==='function'){const fixed=repairTreeConsistency(next);…}}catch(e){}`（参数不被接收 ⇒ 对 `next` 无效） | **新增 try-catch 审计块**：`patch.paths` 命中 `*.children` 或整节点 `nodes.<id>` 时，对 `next.nodes` 逐节点过滤 `children` |
| 过滤逻辑 | — | 剔除 `typeof cid!=='string' || !next.nodes[cid]`（空 / 已删），**同层去重**（保留首次出现顺序） |
| 执行门控 | — | `_childrenPatched`：补丁**不可能写 children**（如仅 `updatedAt` / 标量路径）⇒ 零开销跳过 |
| 结构共享 | — | 仅对**确有洞**的节点以 `Object.assign({},n,{children:_kept})` 替换；`next.nodes` 未被 produce 复制时另建浅拷贝映射后再挂回 ⇒ **旧 state 与补丁值均不被就地改写** |
| 去重检测开销 | — | 第一遍零分配（只判空洞 / 已删）；同层去重：短数组（≤8）O(n²) 免分配，长数组单 Set 探测；均干净 ⇒ 不建 `_kept` |
| 防御性 repair 调用 | `try{…repairTreeConsistency(next)…}catch(e){}` | **逐字保留**（无副作用；不改其签名） |

> **降级 / 契约**：新增变量全部为 `applyPatch` 局部量（不进 `state.nodes`、不改 `juju.store.v31` 序列化形状、不改加密 payload 字段名）；`repairTreeConsistency()` 仍为无参函数（N 层 §A2 断言）；非优化分支（`__l14On()=false` / `_vsUserDisabled=true` / `IS_DESKTOP=false`）行为不变；公开 API（`window.__juIndexShadow` / `window.__juPersistProbe` / `window.__juL9Shadow` / `window.__juL10D1`）零变更；**不新增 `<script>` 块**（9 块不变）。
