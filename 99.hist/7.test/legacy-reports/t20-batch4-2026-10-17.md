### 1 · 折叠钮回归顶栏

```css
/* 改前 */
#topbar .main-toggle{position:fixed;bottom:8px;left:calc(var(--sidebar-left-w) + 4px);...}

body.sb-left-collapsed #topbar .main-toggle.left{left:4px}
/* 改后 */
#topbar .main-toggle{position:static;left:auto;right:auto;bottom:auto;top:auto;transform:none;...}
```

`#btnToggleLeft` / `#btnToggleBoth` 本就在 `#topbar` 首位（DOM 未改，零事件重绑风险）；`static` 下 `left/right/bottom/transform` 会残留生效，故显式复位。

### 3 · 模态 ↔ inert

```js
function _syncAppInert(){
  const app=$('#app');if(!app)return;
  if(_modalStack.some(m=>m&&m.isConnected))app.setAttribute('inert','');else app.removeAttribute('inert');
}
new MutationObserver(()=>_syncAppInert()).observe(document.body,{childList:true});
```

`appConfirm` 打开后显式调用一次、`popStack` 出栈时再调用一次；其余模态（设置 / 解锁 / 导入 / 主题 / 帮助…）由观察器统一收口。以 `isConnected` 判定实际挂载，避免栈内死引用导致 `inert` 粘滞。
