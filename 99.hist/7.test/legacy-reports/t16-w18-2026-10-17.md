## 一、动因与范围

- **动因**：错误上报链的脱敏只覆盖「带引号的用户输入」，裸 PII（手机号 / 邮箱 / 内网 IPv4）可在本地日志与（显式配置端点时的）上报载荷中留存，属隐私保护缺口。
- **范围**：仅 [`canonical`](../../6.P0-L3基线/v2.0-l3.html.html:1) + step9 镜像 + 登记 / 门禁口径 + N 层用例 / 证据 / 波报告；**不新增纳编物**（登记方数保持 **43**）。

## 二、实现

| 接缝 | 改前 | 改后 |
|---|---|---|
| 引号包裹文本 | `/["'`]([^"'`\n]{4,})["'`]/g` → `"<redacted>"` | **原样保留**（替换链首位 · 保持原有匹配优先级） |
| 手机号 | — | `/\b1[3-9]\d{9}\b/g` → `<phone>` |
| 邮箱 | — | `/\b[\w.+-]+@[\w-]+(?:\.[\w-]+)+\b/g` → `<email>` |
| IPv4 | — | `/\b(?:\d{1,3}\.){3}\d{1,3}\b/g` → `<ip>` |
| 加密模式 | `ui.encrypted` ⇒ `msg`/`reason` 置 `<enc-message>` | **原样保留**（`if(encNow){…}else{…}` 分支结构与顺序不变，脱敏仅在非加密分支执行） |

改动后函数（canonical 现行 15961–15967）：

```js
/* FIX-ERR-PII: 消息级脱敏——引号包裹的连续文本（可能含节点标题/用户输入）替换为 <redacted>，防 PII 随错误上报外泄 */
/* L16-W18 · 指令 9（Defect-H）：补充裸手机号 / 邮箱 / IPv4 脱敏（原规则仅匹配引号包裹文本，裸 PII 会原样进入 __juLog）。
   替换链顺序 = 引号包裹（保留原规则 · 先吃掉引号内文本）→ 手机号 → 邮箱 → IPv4；三条补充规则均以 \b 锚定完整 token，
   正常错误消息（如 Column 'foo' not found / timeout after 5000 ms）不被改写；加密模式仍走 <enc-message> 占位分支。 */
const _redactErrText=s=>String(s==null?'':s)
  .replace(/["'`]([^"'`\n]{4,})["'`]/g,'"<redacted>"')
  .replace(/\b1[3-9]\d{9}\b/g,'<phone>')
  .replace(/\b[\w.+-]+@[\w-]+(?:\.[\w-]+)+\b/g,'<email>')
  .replace(/\b(?:\d{1,3}\.){3}\d{1,3}\b/g,'<ip>');
```

> **决策记录 L16-W18-D1（替换链顺序与锚定口径）**：① 引号规则**保持首位**，确保原有「引号内文本整体替换」语义逐字不变（避免补充规则先命中引号内的电话号码，改变既有输出）；② 三条补充规则一律以 `\b` 锚定完整 token，保证 `Column 'foo' not found`（3 字符引号内容）、`timeout after 5000 ms` 等正常消息零改写；③ 不引入任何状态 / 缓存 / 分支，纯字符串变换 ⇒ 幂等（`redact(redact(x)) === redact(x)`）。
> **降级 / 契约**：`state.nodes` 结构、`juju.store.v31` 序列化形状、加密 payload 字段名零变更；公开 API（`window.__juIndexShadow` / `window.__juPersistProbe` / `window.__juL9Shadow` / `window.__juL10D1`）零变更；`__l14On()` / `_vsUserDisabled` / `IS_DESKTOP` 相关分支不涉及（本函数无优化开关）；**不新增 `<script>` 块**（9 块不变）。
