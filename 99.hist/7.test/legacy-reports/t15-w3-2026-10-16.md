| # | 位置 | 变更 |

| B | **系统文件夹选择器（分层降级）** | ① **桌面（Tauri）**：`desktopInvoke('pick_directory')`（能力探测 · 命令不可用则降级）；② **Web**：`window.showDirectoryPicker({mode:'readwrite'})`（申请**读写**授权）；③ **降级**：`input[webkitdirectory]`（跨端可用）。**用户取消（`AbortError` / `NotAllowedError` / 取消回调）保持原路径**并提示。 |
| C | **持久化** | 新状态 `ui.backupDir`（默认 `''` = 默认路径）；Web / 明文经 [`_saveUINow()`](../../6.P0-L3基线/v2.0-l3.html.html:5145) 写入 `UI_KEY`；桌面经 [`uiSnapshot()`](../../6.P0-L3基线/v2.0-l3.html.html:14310) → `save_state` payload；**重启读取**经 [`applyUIFields()`](../../6.P0-L3基线/v2.0-l3.html.html:5103)（`backupDir` 归一化恢复）。 |
| D | **与自动备份联动** | [`backupOnClose()`](../../6.P0-L3基线/v2.0-l3.html.html:17523) 在原有 `saveAutoBackup(true)` 之外：若 `juBackupDirEffective()` 有效且具备写入通道（目录句柄 / 桌面），额外**导出一份完整备份**至所选目录（`juWriteBackupToDir()`）；**路径无效 → 回退默认**（`_juGuardBackupDir()` 启动即校正并提示）。 |
| E | **异常处理** | ① **写入权限**：`showDirectoryPicker({mode:'readwrite'})` 以读写入授权（拒授权即视为不可写）；② **系统关键目录拦截** `_juBlockedDir()`：Windows（盘符根 / `Windows` / `Program Files` / `ProgramData`）+ Unix（`/`、`/bin`、`/etc`、`/usr`、`/var` …）；③ **跨平台路径差异**：`_juNormDir()` 反斜杠 → 正斜杠、去尾斜杠后统一比较。 |

- **既有能力复用**：不改动 `saveAutoBackup` / 加密自动备份 / 配额守卫 / 桌面 SQLite 落盘主路径；仅**附加**目录导出与配置持久化。
- **性能（G-2 / G-5）**：目录导出仅在**关闭时**触发，且**仅在**具备写入通道时构建快照，不影响周期备份节流与渲染。
