## 一、动因与范围

- **动因**：落实《优化指令 · 指令 6》。`repairTreeConsistency` 是 `mergeRemoteState` 尾部的必跑收口；其「每次调用重建全量 Set」在结构共享（structural sharing）语境下是**纯冗余分配**——未变更节点的 children 集合跨调用恒等，却每次被丢弃重建。目标：**复用未变节点的 children Set，仅新增/替换节点重建**，把「连续广播」的累计分配对象数压下来。
- **范围**：仅 [`canonical`](../../6.P0-L3基线/v2.0-l3.html.html:1) + step9 镜像 + 登记 / 门禁口径 + 波报告 / 证据；**不新增纳编物**（登记方数保持 **43**）。

## 二、实现（模块级 WeakMap 缓存 + 失效点）

### 2.1 声明载体与失效辅助（canonical · script_0 · [`repairTreeConsistency`](../../6.P0-L3基线/v2.0-l3.html.html:1919) 同址）

```js
let _childSetCache=new WeakMap();
function _childSetDrop(n){try{if(n)_childSetCache.delete(n);}catch(e){}}
```

- **`_childSetCache`**：`node → Set(children)`。以**节点对象引用**为键——结构共享下「未变节点引用稳定」，故跨调用天然命中；被替换/克隆的节点（新引用）自动 miss 重建。
- **`_childSetDrop`**：失效辅助（就地改写 children 处调用）。

### 2.2 `_getChildSet` 读缓存（第一遍）

| 接缝 | 位置 | 处置 |
|---|---|---|
| 缓存读写 | [`repairTreeConsistency`](../../6.P0-L3基线/v2.0-l3.html.html:1926) | `let s=_childSetCache.get(node); if(!s){s=new Set(node.children||[]);_childSetCache.set(node,s);}`（原 `_childSets` Map + `new Set(...)`） |
| 未变节点 | 同址 | 命中缓存 ⇒ **零分配**；仅新增 / 替换节点重建 |

### 2.3 第二遍复用缓存 Set 作 `seen`（免每父分配 + 恒等）

| 接缝 | 位置 | 处置 |
|---|---|---|
| 复用 `seen` | [`repairTreeConsistency`](../../6.P0-L3基线/v2.0-l3.html.html:1957) | `let seen=_childSetCache.get(p); if(!seen){seen=new Set();_childSetCache.set(p,seen);} seen.clear();`（原 `const seen=new Set()`） |
| stray 剔除 | 同址 | `if(c.parent!==pid){p.children.splice(i,1);i--;seen.delete(cid);}`（**同步从缓存剔除**，使第二遍结束后缓存 == 存活 children 集） |

> **恒等不变量**：第二遍 `clear()` 后就地重填为存活 children 集 ⇒ 每次 repair 收尾时，`_childSetCache.get(p)` **恒等于** `Set(p.children)`（去重 + stray 剔除后）。这既避免每父 Set 分配，又消除跨调用陈旧风险。

### 2.4 失效点（mergeRemoteState 就地改写 / initStore 整体替换）

| 接缝 | 位置 | 处置 |
|---|---|---|
| 新节点挂父 | [`mergeRemoteState`](../../6.P0-L3基线/v2.0-l3.html.html:1673) | `pp.children.push(id)` / root push 后 `_childSetDrop(pp)` / `_childSetDrop(root)` |
| 覆盖分支 | 同址（1708 / 1711 / 1720） | `dp.children.splice(...)` / `rn.children=...` / `oldP.children.splice(...)` 后 `_childSetDrop(...)` |
| 墓碑剔除 | 同址（[`pruneTombstonedChildren`](../../6.P0-L3基线/v2.0-l3.html.html:1648)） | `n.children=filtered` 后 `_childSetDrop(n)` |
| 整体替换 | [`initStore`](../../6.P0-L3基线/v2.0-l3.html.html:2089) | `state=initial` 后 `_childSetCache=new WeakMap();`（旧节点引用缓存作废） |

> **降级 / 契约**：`_getChildSet` 对空/非对象节点返回空 Set，行为与旧口径等价；缓存命中与否**不改变修复结果**（第二遍恒等重填 + 结构共享天然失效）。数据契约（`state.nodes` 结构 / `juju.store.v31` 序列化形状 / 加密 payload 字段名）与公开 API（`window.__ju*` 探针）**零变更**；**不新增 `<script>` 块**（9 块不变）。
