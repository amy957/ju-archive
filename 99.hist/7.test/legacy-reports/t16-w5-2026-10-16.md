## 二、实现（时间网格轮询自管理 visibilitychange）

### 2.1 声明载体与清理（canonical · script_2 / 时间网格定时器段）

在 [`tgTotalH`](../../6.P0-L3基线/v2.0-l3.html.html:8823) / [`clearCalTgTimer`](../../6.P0-L3基线/v2.0-l3.html.html:8826) 同址段：

```js
let _calTgTimer=null,_calTgAutoKey='',_calTgPrevScroll=null,_calTgLastView='';
let _calTgVisHandler=null;                 /* 可见性监听句柄（与 _calTgTimer 同生命周期） */
function clearCalTgTimer(){
  if(_calTgTimer){clearInterval(_calTgTimer);_calTgTimer=null;}
  if(_calTgVisHandler){document.removeEventListener('visibilitychange',_calTgVisHandler);_calTgVisHandler=null;}
}
```

- `clearCalTgTimer` 由「仅清 interval」扩为**同时注销可见性监听**：全仓既有调用点（`renderCalendarPage` 重渲染、`pagehide` / `beforeunload`、`tick` 自检）随之统一收口 ⇒ 不会因重渲染重复挂载监听。

### 2.2 startCalTgTimer 接缝（tick 闭包 + 自停自启）

| 接缝 | 位置 | 处置 |
|---|---|---|
| 轮询体抽为闭包 | [`startCalTgTimer()`](../../6.P0-L3基线/v2.0-l3.html.html:9035) | `_calTgTimer=setInterval(()=>{…},60000)` → `const tick=()=>{…}`（体逐字保留） |
| 自停自启监听 | `startCalTgTimer` 尾部 | `_calTgVisHandler=()=>{ if(document.hidden){ if(_calTgTimer){clearInterval(_calTgTimer);_calTgTimer=null;} } else if(!_calTgTimer&&line.isConnected){ tick(); _calTgTimer=setInterval(tick,60000); } };` |
| 注册监听 | 同上 | `document.addEventListener('visibilitychange',_calTgVisHandler);` |
| 前台启动 | 同上 | `if(!document.hidden)_calTgTimer=setInterval(tick,60000);`（初始状态在后台则不启动） |

> **「view===week」等价判定**：时间线（`line`）仅在周视图挂载；非周视图经 `renderCalendarPage` 已 `clearCalTgTimer`。故 `line.isConnected` ⇔「当前 view===week 且时间线已挂载」。回前台在非周视图下 `line.isConnected=false` ⇒ 不重启（行为不变）。
> **回前台即时重定位**：重启时先 `tick()` 一次（而非等下一个 60s），使红线立即回到当前时刻（覆盖休眠期跨天：`ds!==lastDate` 分支照常触发日期更新 + `forceRender`）。

### 2.3 红线守持（降级 / 契约）

- **非优化分支保留**：初始在后台（`document.hidden` 真）不启动轮询；`line` 未挂不重启；无 `visibilitychange`（异常环境）时 `document.hidden` 恒 `false` ⇒ 直接启动，行为与旧口径一致。
- **数据契约零变更**：`_calTgVisHandler` 为模块级变量 + DOM 事件监听，**不写入 state / 序列化 / 加密 payload / patch 形状**；
- **公开 API 冻结**：`window.__juIndexShadow` / `window.__juPersistProbe` / `window.__juL9Shadow` / `window.__juL10D1` 方法名与返回形状零变更；
- **不新增 `<script>` 块**（9 块不变）。
