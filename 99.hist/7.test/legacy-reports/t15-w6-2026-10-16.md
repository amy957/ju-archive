## 二、实现内容（模块 `juBorderAnchor` + 图谱 / 导图侧接线 · 算法 / 响应 / 绘制 / 节流）

### 2.1 核心算法 —— 外边框盒最近交点（`juBorderAnchor`）

新增顶层共用函数 [`juBorderAnchor()`](../../6.P0-L3基线/v2.0-l3.html.html:11915)（位于导图脚本块 · 图谱脚本块其后可直接引用）：以节点**最外层容器外边框盒（Border Box）**为边界，自节点中心向对端中心引射线，取与**外扩 `pad` 后边框**的最近边交点。节点自身 `padding`（图谱 `4px 10px` / 导图 `5px 12px`）使锚点落于边框 + 外扩 `PAD`，**绝不侵入文字、绝不连中心**。

```js
function juBorderAnchor(cx,cy,hw,hh,tx,ty,pad){
  const px=(pad>0?pad:0);
  const ex=hw+px, ey=hh+px;
  const dx=tx-cx, dy=ty-cy;
  const adx=dx<0?-dx:dx, ady=dy<0?-dy:dy;
  if(adx<1e-6&&ady<1e-6)return{x:cx,y:cy-ey};
  let t=Infinity;
  if(adx>1e-6){const tt=ex/adx;if(tt<t)t=tt;}
  if(ady>1e-6){const tt=ey/ady;if(tt<t)t=tt;}
  if(!isFinite(t))t=0;
  return{x:cx+dx*t, y:cy+dy*t};
}
```

### 2.2 图谱（`renderGraph` / `GraphRenderer`）—— 锚点 + 增量补丁 + 视口裁剪（G-2 / G-5）

- **连线端点**：由中心坐标改为**外边框锚点**。中心取布局坐标（`renderer.lastX/lastY` 优先，否则初始 `positions`）；半宽高取尺寸缓存（缺失时于 rAF 内以 `getBoundingClientRect` 节流测量）。核心在 [`gDrawEdge()`](../../6.P0-L3基线/v2.0-l3.html.html:12744)：

```js
const gDrawEdge=(ge,cull)=>{
  const c1=gCenter(ge.ia),c2=gCenter(ge.ib);
  const s1=gSize.get(ge.aId)||gMeasure(ge.aId),s2=gSize.get(ge.bId)||gMeasure(ge.bId);
  if(!s1||!s2)return;
  const p1=juBorderAnchor(c1.x,c1.y,s1.hw,s1.hh,c2.x,c2.y,G_PAD);
  const p2=juBorderAnchor(c2.x,c2.y,s2.hw,s2.hh,c1.x,c1.y,G_PAD);
  if(cull&&!gInView(p1,p2)){gCulled.add(ge);return;}
  gCulled.delete(ge);
  ge.line.setAttribute('x1',p1.x);ge.line.setAttribute('y1',p1.y);
  ge.line.setAttribute('x2',p2.x);ge.line.setAttribute('y2',p2.y);
};
```

- **增量补丁（changedIds）**：`gEdges` 记录每连线端点的节点 id；`gDirtyNodes`（尺寸变化）/ `gDirtyEdges`（待重绘连线）驱动**仅重算受影响连线**（[`gFlush()`](../../6.P0-L3基线/v2.0-l3.html.html:12736)）；初始化后**不做全局 O(E) 重算**。
- **ResizeObserver（G-1）**：观察每个 `.graph-node`，文字换行撑高容器时 `gDirtyNodes.add(id)` → 失效尺寸缓存 → **单 rAF 重绘关联连线**。
- **视口裁剪（G-5）**：`gInView` 以渲染器可视区（含 40px 余量）判定；被裁剪连线记入 `gCulled`，滚动时（`onScroll`，rAF 节流）仅重估这些连线。
- **z-index**：`svg.style.zIndex='0'`（[连线层置底](../../6.P0-L3基线/v2.0-l3.html.html:12700)）+ 节点 `el.style.zIndex='1'` —— 连线层不再压住节点文字。

### 2.3 思维导图（`renderMindmap`）—— 外框盒锚点 + 单 rAF 节流（G-1 / G-2）

- **连线骨架**：先建路径（记录 `from/to` id，[`_mmEdgeList`](../../6.P0-L3基线/v2.0-l3.html.html:11959)），待节点挂载测量后按外边框锚点重算 `d`（bezier 控制点取两锚点中点 x）。
- **尺寸来源**：canvas 施加了 `scale` 变换，`getBoundingClientRect` 返回**被缩放坐标**，故导图侧改用**未缩放外框盒**（`offsetLeft/offsetTop/offsetWidth/offsetHeight`）取世界坐标（[测量块](../../6.P0-L3基线/v2.0-l3.html.html:12068)）。
- **ResizeObserver + 增量**：`_mmRO` 观察每个 `.mm-node`；`_mmDirty` 收敛受影响节点 → 仅重算 dirty 节点关联连线（[`_mmFlush()`](../../6.P0-L3基线/v2.0-l3.html.html:12097)），初始化后**严格增量**；`_mmInView` 亦做视口裁剪。
- **z-index**：`svg.style.zIndex='0'`（[导图连线层置底](../../6.P0-L3基线/v2.0-l3.html.html:11947)）；节点 DOM 在其后，连线不压文字。
- **视图回收**：`wrap._cleanup`（[导图侧](../../6.P0-L3基线/v2.0-l3.html.html:12146)）断开 ResizeObserver + 取消在途 rAF；[`renderMain()`](../../6.P0-L3基线/v2.0-l3.html.html:13278) 在清空 `#content` 前调用旧 `.mm-wrap` 的 `_cleanup`（与图谱 `.graph-canvas` 同范式）。

### 2.4 拖拽节流优化说明

- **图谱**：拖拽 `pointermove` 由 [`gMarkNode(dragId)`](../../6.P0-L3基线/v2.0-l3.html.html:12750) 处理 —— 仅将该节点关联连线入脏并**单 rAF 合并**多次移动（原实现每次 `pointermove` 直接 `updateLines()` 重写全部 `<line>`）；节点变换仍由 `setDraggingPosition` 即时更新，锚点随之重算。
- **导图**：节点自由拖动的 `onMM` 内 `_mmMark(nd.id)` —— 仅重算该节点关联连线，单 rAF 节流。
- **getBoundingClientRect**：仅在 rAF 批量刷新中、对 **dirty 节点**调用（图谱 `gMeasure`），并且带尺寸缓存（命中即免测）；绝不在 `pointermove`/`scroll` 高频回调内直接测量 —— 满足 G-2「必须节流或使用 requestAnimationFrame」。

- **无结构性 HTML 变更**：不新增 `<script>` 块（**inline script 块数 = 9 不变**）；不新增纳编物。
