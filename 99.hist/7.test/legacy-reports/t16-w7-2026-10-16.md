## 一、动因与范围

- **动因**：落实《优化指令 · 指令 7》。`collectSubtreeIdsFromPreState` 是 `markPersistFromPatch` 硬删补全（I-1 commit / I-2 undo / I-3 redo）路径的子树 id 采集器；`roots.filter(Boolean)` + `pop/push` 混用在大型子树下会触发多次数组扩容。目标：以**确定的单遍前向游标**替代 `pop/push` 混用，去掉 `filter(Boolean)` 的一次性拷贝分配。

## 二、实现（显式索引游标队列）

### 2.1 改前口径（旧）

```js
function collectSubtreeIdsFromPreState(pre,rootIds){
  const nodes=(pre&&pre.nodes)?pre.nodes:(pre||{});
  const ids=new Set();
  const roots=Array.isArray(rootIds)?rootIds:(rootIds?[rootIds]:[]);
  const stack=roots.filter(Boolean);          /* ← 一次性 filter 拷贝 */
  while(stack.length){
    const id=stack.pop();                     /* ← pop / push 混用 */
    if(!id||ids.has(id))continue;
    ids.add(id);
    const n=nodes[id];
    if(n&&Array.isArray(n.children)){for(const cid of n.children)if(cid&&!ids.has(cid))stack.push(cid);}
  }
  return ids;
}
```

### 2.2 改后口径（本波 · 索引游标）

```js
function collectSubtreeIdsFromPreState(pre,rootIds){
  const nodes=(pre&&pre.nodes)?pre.nodes:(pre||{});
  const ids=new Set();
  const roots=Array.isArray(rootIds)?rootIds:(rootIds?[rootIds]:[]);
  const queue=[];
  for(let i=0;i<roots.length;i++)queue.push(roots[i]);   /* ← 单次传入直接初始化，不再 filter(Boolean) */
  let head=0;                                            /* ← 显式索引游标 */
  while(head<queue.length){
    const id=queue[head++];                              /* ← 前向出队，无 pop/push 混用 */
    if(!id||ids.has(id))continue;                        /* ← 循环内 if(!id) 守卫 */
    ids.add(id);
    const n=nodes[id];
    if(n&&Array.isArray(n.children)){for(const cid of n.children)if(cid&&!ids.has(cid))queue.push(cid);}
  }
  return ids;
}
```

| 接缝 | 改前 | 改后 |
|---|---|---|
| 建队 | `stack=roots.filter(Boolean)`（一次拷贝 + 剔除 falsy） | `queue=[]; for(i) queue.push(roots[i])`（直接初始化；falsy 由循环内 `if(!id)continue` 守卫） |
| 出队 | `stack.pop()`（LIFO，与 `push` 混用） | `queue[head++]`（前向游标 · FIFO，无 pop/push 混用） |
| 复杂度 | `O(n)` | `O(n)`（不变） |
| 结果 | `Set` 子树 id 全集 | **逐位（元素集）相等**（见 N 层 §B/§D） |

> **降级 / 契约**：`pre` 为 `{nodes}` 或 `nodes` 映射本身、`rootIds` 为数组 / 单值 / 空 的全部路径行为与旧口径等价（`null` / `undefined` 由循环内守卫剔除）。数据契约（`state.nodes` 结构 / `juju.store.v31` 序列化形状 / 加密 payload 字段名）与公开 API（`window.__ju*` 探针）**零变更**；**不新增 `<script>` 块**（9 块不变）。
