## 二、实现

### 2.1 P1-4 · `_logTimers` 上限（500）

```js
const _logTimers=new Map();
const LOG_TIMER_MAX=500; /* L17-W4 · P1-4 */
```

```js
    if(type==='mod'){
      const prev=_logTimers.get(key);
      if(prev)clearTimeout(prev.timer);
      if(!prev&&_logTimers.size>=LOG_TIMER_MAX){
        const oldestKey=_logTimers.keys().next().value;
        if(oldestKey!==undefined){
          const old=_logTimers.get(oldestKey);
          _logTimers.delete(oldestKey);
          if(old){clearTimeout(old.timer);try{old.commit();}catch(e){}}
        }
      }
      const timer=setTimeout(()=>{ _logTimers.delete(key); doCommit(); },1500);
      _logTimers.set(key,{timer,commit:doCommit});
```

- 仅在**新增 key**且已达上限时淘汰（同一 key 的防抖刷新不触发淘汰）；淘汰项 **clearTimeout + 立即 commit**，不丢日志。
- 淘汰顺序 = `Map` 插入序（最早登记项）；单次最多淘汰 1 项，容量恒 ≤ 500。

### 2.2 P1-5 · 图谱 worker 单次超时即重建

```js
  _timeoutHit(gen){
    if(!this.pending||this.pending.gen!==gen)return;
    this.timeoutStrikes++;
    console.warn('[graph-worker] 超时，terminate 重建');
    this._rejectPending(new Error('timeout'));
    if(this.worker){try{this.worker.terminate();}catch(e){}this.worker=null;}
    if(this.url){try{URL.revokeObjectURL(this.url);}catch(e){}this.url=null;}
    this.ready=false;
    this.timeoutStrikes=0;
  }
```

- 删除 `timeoutStrikes>=2` 分支；`gen` 匹配守卫保留（过期超时不影响新请求）；`timeoutStrikes` 字段语义保留并在命中后归零。
