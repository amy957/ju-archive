## 一、动因与范围

- **动因**：`sanitizeHtml` 是编辑 / 粘贴 / 导入 / 落盘回填的统一入口，非幂等会使「净化一次」与「净化两次」产生不同 state 文本；表格上下文的文本位移还会把内容搬到表格之外（视觉与索引口径漂移）。
- **范围**：仅 [`canonical`](../../6.P0-L3基线/v2.0-l3.html.html:1) + step9 镜像 + 登记 / 门禁口径 + N 层用例 / 证据 / 波报告；**不新增纳编物**（登记方数保持 **43**）。

## 二、实现

| 接缝 | 改前 | 改后 |
|---|---|---|
| 非白名单标签回填 | `ch.parentNode.replaceChild(doc.createTextNode(ch.textContent||''),ch);return;` | 文本先经 `_sanTextEsc`（`<` → `\u003C`，`>` → `\u003E`）→ `createTextNode`；表格类父上下文前置于最近 `TABLE` 之前 |
| 文本转义 | 无显式守卫（依赖 innerHTML 序列化） | 新增 [`_sanTextEsc`](../../6.P0-L3基线/v2.0-l3.html.html:1491) 单点助手 |

改动后分支（canonical 现行 1504–1520）：

```js
          if(!SAFE_TAGS.has(tag)){
            /* L16-W16 · 指令 7（Defect-D）：非白名单标签以文本回填（文本先经 _sanTextEsc 固化尖括号）。
               表格类父上下文（TABLE/THEAD/TBODY/TFOOT/TR/COLGROUP）中的文本在再次解析时会被
               foster parenting 移出表格，故按解析器同口径前置于最近 TABLE 之前，保证回填结果幂等。 */
            const rawText=_sanTextEsc(ch.textContent||'');
            const textNode=doc.createTextNode(rawText);
            const par=ch.parentNode;
            if(!par)return;
            const ptag=par.nodeType===1?(par.tagName||''):'';
            if(ptag==='TABLE'||ptag==='THEAD'||ptag==='TBODY'||ptag==='TFOOT'||ptag==='TR'||ptag==='COLGROUP'){
              let tbl=par;
              while(tbl&&tbl.tagName!=='TABLE')tbl=tbl.parentNode;
              if(tbl&&tbl.parentNode&&tbl!==ch){tbl.parentNode.insertBefore(textNode,tbl);par.removeChild(ch);return;}
            }
            par.replaceChild(textNode,ch);return;
          }
```

> **决策记录 L16-W16-D1（显式转义 + 表格上下文前置）**：经实测（Chromium，DOMParser `text/html`），文本节点经 `innerHTML` 序列化时字面 `<` / `>` 已被转义为 `<` / `>`，指令草案描述的「字面 `<` 存活」在本运行时不再直接出现；而验收语料中的真实非幂等落在**表格上下文文本位移**（`F28`：`<table><caption><b>c</b></caption>…` → 回填文本留在 `table` 内，二次解析被移到表格之前）。本波按目标语义实现：① 按指令显式固化尖括号转义（守卫 + 可读性，不改变既有可见文本、不产生二次转义）；② 同址补齐 foster parenting 同口径前置，使 `sanitizeHtml(sanitizeHtml(x)) === sanitizeHtml(x)` 对 fuzz 31 例全部成立。措辞与落点参照 L16-W13-D1 先例（草案形状与验收目标不一致时按目标语义实现等价门控）。
> **降级 / 契约**：`state.nodes` 结构、`juju.store.v31` 序列化形状、加密 payload 字段名零变更；公开 API（`window.__juIndexShadow` / `window.__juPersistProbe` / `window.__juL9Shadow` / `window.__juL10D1`）零变更；`__l14On()=false` / `_vsUserDisabled=true` / `IS_DESKTOP=false` 行为不变；**不新增 `<script>` 块**（9 块不变）。
