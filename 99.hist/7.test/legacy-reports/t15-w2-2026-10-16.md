## 二、实现内容（选择模型 · 交互 · 高亮 · 性能）

| # | 位置 | 变更 |
|---|---|---|
| A | **选择模型**（新增模块） | 新增模块级 `_mSel = {type, ids:Set, anchorId, mode, order}`（**仅内存 · 不持久化 · 不入撤销栈**），对齐 `ui.selection` 设计。状态以 **Set** 维护，与 DOM 解耦 → **虚拟滚动 / 重渲染后选择保持**（滚出屏幕再滚回，行从 `_mSel.ids` 重取选中态）。 |
| B | **交互接线** | 文件卡片 [`renderFileCard()`](../../6.P0-L3基线/v2.0-l3.html.html:12906) 与数据库输入行 [`renderDbTable()`](../../6.P0-L3基线/v2.0-l3.html.html:10803) 的 `<tr>`：`Ctrl/Cmd` 单击切换 · `Shift` 范围（按视图模型 `order` 序列）· 单击单选（数据库行）；工具栏新增「全选」按钮（文件夹网格 + 数据库）；全局 **`Ctrl/Cmd+A`** 全选当前视图（大纲 / 文件 / 数据库）；**`Esc`** 清除；**编辑态（`input` / `contenteditable` / `select`）不劫持 `Ctrl+A`**，保留原生文本全选。 |
| C | **选中高亮** | 新增 `.file-card.ju-msel` 与 `.db-table tbody tr.ju-msel td`（`--accent-soft` 背景 + `--accent` 内阴影 / 边框）→ 选中项**明显背景视觉反馈**（类名 `ju-msel` 唯一，规避既有 `.m-sel` 复用冲突）。 |
| D | **性能（G-2 / G-5）** | `_mSelPaint()` 经 **`requestAnimationFrame` 合批**，仅刷新可见 `[data-msid]` 行的选中标记（**不整树重渲染 / 不逐行同步渲染**）；**全选基于视图模型 `order`（非 DOM）**，大纲视图全选走 [`outlineVisibleSeq()`](../../6.P0-L3基线/v2.0-l3.html.html:7059) → **虚拟滚动下不漏选**。 |

- **G-1 文本自适应**：高亮仅作用于容器背景 / 边框，不改变文本换行与撑开策略；文本自适应（G-1）本体不变。
- **既有能力复用**：大纲视图多选（[`toggleOutlineSel()`](../../6.P0-L3基线/v2.0-l3.html.html:7068) / [`outlineSelectRange()`](../../6.P0-L3基线/v2.0-l3.html.html:7074)）保持原样，本波仅补 `Ctrl/Cmd+A` 全选。
- **打印**：既有 `@media print` 规则不受影响——「打印隐藏非内容元素」守持。
