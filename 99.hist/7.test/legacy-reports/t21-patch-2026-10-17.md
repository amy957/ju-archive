## 二、变更内容（P0-1）

### 2.1 CSS

| 选择器 | 声明 | 作用 |
|---|---|---|
| `.db-table th.dragging` | `opacity:.5` | 拖拽源列头半透明反馈 |
| `.db-table th.drag-over` | `box-shadow:inset 2px 0 0 var(--accent)` | 落点列左侧强调条 |

### 2.2 交互与数据写入

1. 列头（`th`）设为 `draggable=true` 并记录 `th.dataset.field`，字段名统一归一（`string` / `object` 字段一律取 `name`）。
2. `dragstart`：`ui._resizingCol` 为真时 `preventDefault()` 直接返回（**列宽拖拽期间禁用 HTML5 拖拽**，避免与 resize 句柄连带触发）；否则写入模块级 `_dragFieldName`，并置 `.dragging`、清理残留 `.drag-over`。
3. `dragover`：命中非源列时置 `.drag-over` 并设 `dropEffect='move'`；`dragleave` / `dragend` 经 `_clearDragOver()` 复位视觉态。
4. `drop`：读取 `_from=_dragFieldName` / `_to=fn`，先复位视觉态与 `_dragFieldName`；随后**单次 `commit` 内完成原子换位**——`splice(fromIdx,1)` 取出后 `splice(toIdx,0,moved)` 插入，并以 `{snapshot:true}` 入历史栈（可撤销 / 可重做）。
5. 列宽拖拽收尾 `finally` 中恢复 `th.draggable=true`，视觉态零残留。

### 2.3 边界与防线

- `fromIdx<0 || toIdx<0 || fromIdx===toIdx` 一律提前返回，不产生空提交。
- `Array.isArray(s.dbFields)` 守卫；`_from===_to` 直接返回，避免同列自拖入栈。
- `setData` / `getData` / `dropEffect` 均包裹 `try{}catch{}`，非标准宿主环境下静默降级。
- 与既有右键菜单（重命名 / 左移 / 右移 / 插入 / 删除列）并存：拖拽为新增入口，原路径逐字保留。
