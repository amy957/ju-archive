## 二、实现

### 2.1 行数据派生（`buildTagIndex()` 的真实返回形状）

`buildTagIndex()` 返回 **`Map<tag, Set<id>>`**（[`_tagScanStep`](../../6.P0-L3基线/v2.0-l3.html.html:15745) 内 `map.set(t,new Set()); map.get(t).add(id);`），索引值为 **`Set`，无 `length` 属性**。故计数必须取 `size`：

```js
/* L17-W1 · 指令 1（Defect-P0-1）：原实现此处直接 tags.forEach(...)，而 tags 从未在本作用域声明
   （全文件不存在全局 tags）→ 用户展开标签分组必抛 ReferenceError，分组恒不渲染。
   改为由 buildTagIndex() 返回的 Map<tag, Set<id>> 派生 [tag,count] 行；计数取 idSet.size
   （索引值为 Set，无 length 属性），按计数降序与原标签视图口径一致；空索引渲染「暂无标签」占位行。 */
const tagRows=Array.from(tagIndex.entries())
  .map(([t,idSet])=>[t,(idSet&&typeof idSet.size==='number')?idSet.size:0])
  .sort((a,b)=>b[1]-a[1]);
if(!tagRows.length){
  const empty=document.createElement('div');empty.className='sb-row sb-empty';
  empty.innerHTML='<span class="sb-arrow leaf"></span><span class="sb-icon"></span><span class="sb-label">暂无标签</span>';
  box.appendChild(empty);
}else{
  tagRows.forEach(([t,count])=>{
    /* 原有 row 构建逻辑逐字保留（箭头 / 图标 / 颜色点 / 重命名 / 删除 / 改色 / 计数 / 点击打开） */
  });
}
```

### 2.2 收口对照

| 接缝 | 改前 | 改后 |
|---|---|---|
| 行数据来源 | `tags`（未定义） | `Array.from(tagIndex.entries())` |
| 计数来源 | `count`（第二元组位，来源不明） | `idSet.size`（`Set` 真实规模，非法形状回退 `0`） |
| 排序 | 未排序（依赖旧数组序） | 计数降序 `b[1]-a[1]`（与标签视图口径一致） |
| 空索引 | 直接进入 `forEach`（无行可出，且仍先抛错） | `.sb-row.sb-empty`「暂无标签」占位行 |
| row 构建逻辑 | 原 18 行 | **逐字保留**（仅缩进 +2 空格） |
| 新建标签入口 | 末尾追加 | 末尾追加（空索引时也不丢失） |

> **决策记录 L17-W1-D1（计数取 `idSet.size` 而非 `idSet.length`）**：`buildTagIndex()` 的索引值为 `Set`，`length` 恒为 `undefined`；若沿用 `length`，计数列将渲染为 `undefined`（且排序退化为 `NaN` 比较）。故按 `Set` 语义取 `size`，并以 `typeof idSet.size==='number'` 守卫历史 / 异常形状（回退 `0`，行仍可见）。
> **决策记录 L17-W1-D2（空索引用占位行而非静默空列表）**：标签分组展开后若无任何标签，原设计只剩「＋ 新建标签」一行，用户无法区分「无标签」与「渲染失败」。新增 `.sb-row.sb-empty`「暂无标签」占位行（复用既有 `sb-row` 布局类），同时**保留**新建入口 —— 功能不降级（LO-1）。
> **降级 / 契约**：`state.nodes` 结构、`juju.store.v31` 序列化形状、加密 payload 字段名**零变更**；公开 API（`window.__juIndexShadow` / `window.__juPersistProbe` / `window.__juL9Shadow` / `window.__juL10D1`）零变更；本函数不涉及 `__l14On()` / `_vsUserDisabled` / `IS_DESKTOP` 开关，折叠分支（`!open`）与骨架分支（`_tagIndexCache===null`）**逐字未改**；**不新增 `<script>` 块**（9 块 · 静态语法全通过）。
> **注释保全**：仅新增 4 行 L17-W1 说明注释；既有 `FIX-XXX-N` 历史编号注释（含 `【QA-修复-标签】` / `FIX-L-44` / `FIX-GHOST-TAG` 等）**零清理**。
