## 二、实现

### 2.1 单位归一口径（定义于 `mergeRemoteState` 作用域内，逐字替换原 `_norm`）

```js
/* L16-W21 · 指令 12（Defect-C）：往返时间戳单位统一——秒级（0<v<1e10）×1000、微秒级（v>8.64e14）÷1000，
   正常毫秒（1e12~1e13）原样返回；对端（秒）/ 本地（毫秒）混合快照的 LWW 比较不再出现单位伪影 */
const _normToMs=t=>{const v=+t;if(!(v>0))return v;return v<1e10?Math.round(v*1000):(v>8.64e14?Math.round(v/1000):v);};
const remoteUpdatedAt=_normToMs(remote.updatedAt||0);
```

- **三域映射**：秒级 `0<v<1e10` ⇒ `Math.round(v*1000)`；微秒级 `v>8.64e14` ⇒ `Math.round(v/1000)`；其余（正常毫秒 `1e12~1e13`）**原样返回**。
- **非数值守卫**：`if(!(v>0))return v;` ⇒ `0` / 负值 / `NaN` 原样返回，不被误判为秒级（与旧 `_norm` 的 0 语义一致）。

### 2.2 收口对照

| 接缝 | 改前 | 改后 |
|---|---|---|
| 墓碑守卫（插入分支） | `_norm(rn.updatedAt\|\|0)` | `_normToMs(rn.updatedAt\|\|0)` |
| 覆写分支 LWW | `_norm(rn.updatedAt)>_norm(ln.updatedAt)` | `_normToMs(...)` 两侧 |
| 平局 tie-break | `_norm(rn.updatedAt)===_norm(ln.updatedAt) && _norm(rn.createdAt)===_norm(ln.createdAt)` | `_normToMs(...)` 四处 |
| 覆写分支 `localExtra` | `lcUpd=_norm(lc.updatedAt)` / `lcCrt=_norm(lc.createdAt)` | `_normToMs(...)` |
| 删除传播 | `lnUpd=_norm(ln.updatedAt)` / `lnCrt=_norm(ln.createdAt)` | `_normToMs(...)` |
| 全局元数据 LWW | `remoteUpdatedAt>(state.updatedAt\|\|0)` | `remoteUpdatedAt>_normToMs(state.updatedAt\|\|0)` |
| `remoteUpdatedAt` 取值 | `(remote.updatedAt\|\|0)`（未归一） | `_normToMs(remote.updatedAt\|\|0)` |

> **决策记录 L16-W21-D1（归一函数就地替换而非并列新增）**：`_norm` 是 `mergeRemoteState` 内的**局部 const**，全仓仅该段 11 处调用；并列新增 `_normToMs` 会留下两套口径并存的回退入口（易被后续编辑误用）。故按指令语义「新增 `_normToMs(t)` 函数 + 全部调用替换」执行**逐字重命名 + 三分支扩展**，改后全段 `_norm(` 残留 **0**、`_norm` 标识符零残留（N 层 §A2 锁定）。
> **决策记录 L16-W21-D2（`remoteUpdatedAt` 与 `state.updatedAt` 同口径归一）**：若仅替换节点级调用，`remoteUpdatedAt` 仍以秒参与 `localExtra` / 删除传播 / 全局元数据 LWW 比较，缺陷只修一半（删除不传播依然成立）。故 `remoteUpdatedAt` 取归一值、全局 `state.updatedAt` 在比较处归一 —— 两处均为**比较口径**，不改写任何存储值。
> **降级 / 契约**：`state.nodes` 结构、`juju.store.v31` 序列化形状、加密 payload 字段名零变更；合入节点的原始时间戳**不被就地改写**（比较统一、存储不动）；公开 API（`window.__juIndexShadow` / `window.__juPersistProbe` / `window.__juL9Shadow` / `window.__juL10D1`）零变更；非优化分支（`__l14On()` / `_vsUserDisabled` / `IS_DESKTOP`）不涉及（本段无优化开关）；**不新增 `<script>` 块**（9 块 · 静态段语法全通过）。
> **注释保全**：本次仅新增 2 行 L16-W21 说明注释（旧 `_norm` 行本身无独立注释）；未清理任何 `FIX-XXX-N` 历史编号注释。
