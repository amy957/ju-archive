# JU 笔记 v2.1 · 安装与启动指南

面向最终用户。按顺序执行即可完成安装；若遇到杀毒软件拦截，请直接跳到第二节。

---

## 一、安装与首次启动

### 1. 确认系统环境

- Windows 10 或 Windows 11，**64 位**
- 需要 **Microsoft Edge WebView2 Runtime**（Windows 11 一般已预装）
  - 检查方法：开始菜单搜索「WebView2」或在「设置 → 应用 → 已安装的应用」中查找 *Microsoft Edge WebView2 Runtime*
  - 若未安装：从微软官方页面下载 **Evergreen Bootstrapper**，安装后再继续

### 2. 下载文件

从分发渠道下载以下两个文件，放在**同一个文件夹**内（例如 `下载` 或桌面新建的 `JU` 文件夹）：

| 文件 | 说明 |
| --- | --- |
| `JU-v2.1-win-x64.exe` | 主程序 |
| `JU-v2.1-checksums.txt` | 校验值清单（用于确认文件完整、未被篡改） |

### 3. 校验文件完整性（强烈建议）

`JU-v2.1-checksums.txt` 的内容格式为「哈希值 + 两个空格 + 文件名」：

```
27dba02d6bc143c0cc34040880a4278ac5ff8c79b14641fefe4a649de77043ec  JU-v2.1-win-x64.exe
```

在文件所在文件夹的地址栏输入 `cmd` 并回车，打开命令提示符，执行：

```bat
certutil -hashfile JU-v2.1-win-x64.exe SHA256
```

输出示例：

```
SHA256 的 JU-v2.1-win-x64.exe 哈希:
27dba02d6bc143c0cc34040880a4278ac5ff8c79b14641fefe4a649de77043ec
CertUtil: -hashfile 命令成功完成。
```

**比对方法**：把第二行那串哈希与 `JU-v2.1-checksums.txt` 第一串逐字符比较（不区分大小写）。

- **完全一致** → 文件完整，可继续安装。
- **不一致** → 文件在下载或传输中已损坏，或被第三方修改，**请勿运行**，重新下载后再校验。

> 两个文件必须来自同一来源；只比对其中一处（比如只相信网页上贴的哈希）会削弱校验意义。

### 4. 运行安装

1. 双击 `JU-v2.1-win-x64.exe`。
2. 首次运行可能出现「Windows 已保护你的电脑」提示（SmartScreen）：
   点击 **更多信息 → 仍要运行**。这是未购买代码签名证书的独立分发软件的常见提示，不代表文件有问题——前提是你已在第 3 步完成哈希校验。
3. 按向导完成安装，启动后即可新建第一篇笔记。

### 5. 数据位置与备份

- 笔记数据保存在本机用户目录下的应用数据文件夹内（本地 SQLite 数据库），不上传任何服务器。
- 建议定期使用「导出备份」生成 JSON 文件，自行保存到其他磁盘或网盘。
- 覆盖安装 / 升级**不会**删除已有数据；卸载时若选择保留数据，重装后仍可继续使用。

## 二、杀毒软件误报处理（白名单设置）

JU 笔记为本地优先的独立分发程序，未附带广泛传播的商业签名证书，部分杀毒软件可能依据「未知发布者」「行为启发式」给出拦截提示，属于**误报**。

> 前提：**必须先完成第一节第 3 步的哈希校验且结果一致**，才可按误报处理。哈希不一致时请勿放行。

### 通用步骤

1. 确认文件路径：把 `JU-v2.1-win-x64.exe` 放到一个固定目录，例如 `C:\Program Files\JU\` 或 `D:\Apps\JU\`（避免放在临时目录、下载目录）。
2. 打开杀毒软件的**隔离区 / 保护历史**，找到被拦截的条目，选择「还原」。
3. 打开杀毒软件的**排除项 / 白名单 / 信任列表**，把以下两项加入：
   - **文件**：`JU-v2.1-win-x64.exe`（安装包）
   - **文件夹**：JU 笔记的安装目录（程序本体）与应用数据目录（笔记数据库）
4. 再次运行安装包。

### 常见杀毒软件入口

| 软件 | 设置路径 |
| --- | --- |
| Windows 安全中心（Defender） | 病毒和威胁防护 → 管理设置 → 排除项 → 添加或删除排除项 |
| 360 安全卫士 | 木马查杀 → 信任区 → 添加文件 / 目录 |
| 火绒安全 | 防护中心 → 信任区 → 添加文件 / 目录 |
| 腾讯电脑管家 | 病毒查杀 → 信任区 → 添加文件 / 目录 |

### 若程序被直接删除

1. 先添加排除项（上表路径），再从隔离区还原；若文件已被彻底删除，重新下载并**再次校验哈希**。
2. 若企业环境由 IT 统一管控，请把安装包路径与哈希值提交给管理员，由管理员在终端防护策略中放行。

## 三、常见问题

**Q：启动后白屏或立刻退出？**
A：多为缺少 WebView2 运行时。按第一节第 1 步安装 WebView2 后重试。

**Q：升级会不会覆盖我的笔记？**
A：不会。数据存放在独立的应用数据目录，升级只替换程序本体。升级前仍建议导出一次 JSON 备份。

**Q：如何完全卸载？**
A：在「设置 → 应用」中卸载 JU 笔记；如需彻底清除数据，再手动删除应用数据目录（删除后不可恢复，请先导出备份）。

**Q：软件会联网吗？**
A：不会。除你在设置中主动开启崩溃上报外，应用不发起任何对外网络连接。
