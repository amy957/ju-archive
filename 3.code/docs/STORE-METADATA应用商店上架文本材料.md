## 二、详细描述

JU 笔记是一款**本地优先**的桌面知识库工具。所有笔记默认保存在你自己的电脑上，不经过任何服务器；打开软件即用，断网亦可完整工作。

**五大视图，一套数据**

同一份内容可以随时切换五种呈现方式，无需复制粘贴、不会产生副本：

- **大纲视图**：无限层级的树状笔记，支持拖拽排序、多选、跨层级移动，适合结构化写作与资料整理。
- **多维表格视图**：把笔记当作数据行来管理，按字段筛选、排序、分组，适合任务清单、文献库、素材库等结构化场景。
- **导图视图**：由大纲自动布局的思维导图，用于梳理逻辑与汇报演示。
- **图谱视图**：以节点关系呈现知识网络，快速发现笔记之间的关联与孤岛。
- **幻灯片视图**：把大纲直接转为演示页，边写边讲，无需另做 PPT。

**三端多标签同步（LWW 机制）**

同一份库可同时打开多个窗口、多个标签页并行编辑。冲突合并采用 **LWW（Last-Write-Wins，后写胜出）** 机制：以时间戳判定同一字段的最终值，合并过程确定、可重放，不会出现「互相覆盖整篇笔记」的情况。

**安全加密与本地存储**

- 正文与结构化数据存储于本地 SQLite 数据库，完全离线，不依赖云服务。
- 支持 **AES-GCM** 对称加密，密钥派生自你的口令，加密后的数据即便被拷走也无法直接读取。
- 备份导出为明文 JSON，便于自行归档、迁移与版本管理。

**大规模库不卡顿**

索引与持久化分层设计、增量提交与虚拟滚动协同工作，**3 万节点规模的库可实现极速启动**，滚动与编辑保持稳定响应。

**数据自主**

- 无账号体系，无强制登录，不采集笔记内容。
- 备份文件为通用 JSON 格式，随时可完整导出，不存在锁定。

## 四、权限说明

JU 笔记**仅申请本地文件读写权限**，用于：

1. 读写本地 SQLite 数据库（笔记正文、结构、索引与设置）；
2. 导出 / 导入 JSON 备份文件（由你在保存对话框中主动选择路径）。

**不申请网络请求权限。** 应用在正常运行期间不发起任何对外网络连接，唯一例外是你在设置中**主动开启**的崩溃上报功能——开启后仅在发生崩溃时上传脱敏后的崩溃堆栈，可随时关闭；关闭后应用完全离线。

应用不读取与自身数据无关的目录，不访问联系人、摄像头、麦克风、位置等敏感权限。
