## 二、商标标识

### 2.1 主申请标识（文字商标）

- 标识文字：**JU**
- 字体：无衬线常规体（提交时不指定字体，避免被限定为特定字形）
- 读音：/dʒeɪˈjuː/（英文逐字母）或 /dʒuː/（作为单词）
- 说明：`JU` 为两字母短标，**固有显著性偏弱**，在先注册密度高（见 §六），
  故本次以「文字 + 图形」组合为主申请，纯文字申请作为并列布局。

### 2.2 图形 / 组合商标（建议主推）

| 标识形态 | 说明 | 建议 |
| --- | --- | --- |
| 纯文字 `JU` | 保护范围宽，但近似驳回概率高 | 并列申请（备选） |
| 图形（应用图标） | 需固化一版矢量图，避免后续改版超范围 | 主推 |
| 组合（图标 + `JU`） | 整体显著性最强，驳回概率最低 | **主申请** |
| 指定颜色 | 若图标以固定配色提交，保护范围被限缩 | 不用颜色，黑白提交 |
| 标语 | `JU 笔记` 作为副标使用，可另行评估 | 视使用证据决定 |

**使用证据沉淀要求**：申请前建议已具备可证明的使用证据（应用商店页面、官网、安装包命名
`JU-vX.Y-win-x64.exe`、分发页截图、带日期的版本发布记录），以备答复审查意见或主张在先使用。

对应的「多端同步 / 托管服务」在当前版本**尚未上线**（见
[`../BUSINESS/LICENSE-SYSTEM.md`](../BUSINESS/LICENSE-SYSTEM.md) §5.2）。
若为节省费用而暂不指定，须在同步服务**上线前**补交同类申请，避免被抢注；
若一次性指定，则须确认不构成「无正当理由连续三年不使用」的撤销风险敞口（《商标法》第四十九条）。

**申请理由与现状口径**：

- JU 当前为**本地优先（local-first）**应用，不存在云端存储与账号体系
  （见 [`../PRIVACY.md`](../PRIVACY.md) §1）。第 42 类属于**防御性 / 前瞻性布局**，
  覆盖「自动更新分发服务」「未来可选的多端同步 / SaaS 形态」「技术支持服务」三类使用场景；
- 为避免与实际经营不符，第 42 类申请不主张「已提供云存储服务」，仅主张
  「软件更新 / 维护 / 设计 / 咨询」等**当前真实发生**的服务（自动更新端点、版本发布与技术支持）；
- 若后续上线同步服务，应在该服务上线**之前**完成第 42 类注册或至少提交申请，避免被抢注。

## 五、优先权主张（Priority Claim）

1. **法律依据**：
   - 《保护工业产权巴黎公约》第四条（同盟国间 6 个月优先权）；
   - 《中华人民共和国商标法》第二十五条（自商标在外国第一次提出注册申请之日起
     六个月内，又在中国就相同商品以同一商标提出申请的，可享有优先权）；
   - 《马德里协定关于国际注册的议定书》第四条（国际注册可主张在先申请优先权）。
2. **时间轴**：

   | 节点 | 日期 | 说明 |
   | --- | --- | --- |
   | T0（首次申请日） | 【待填：YYYY-MM-DD】 | 建议在中国大陆首次提交 |
   | T0 + 6 个月 | 【待填：自动计算】 | **优先权期限届满日**，逾期不可恢复 |
   | T1（马德里/直接申请） | 须 ≤ T0 + 6 个月 | 否则只能以 T1 为新的申请日 |

3. **主张要件（缺一不可）**：
   - 后续申请须与首次申请为**同一商标**、**相同商品/服务**（超出部分不享有优先权）；
   - 提交时须声明优先权，并在规定期限内提交首次申请**副本**（经证明）；
   - 首次申请若被撤回/驳回/放弃，不影响已产生的优先权。
4. **操作纪律（内部）**：
   - T0 之前**不得**在任何公开渠道（应用商店、官网、公开仓库 README）披露图形商标终稿，
     避免被他人抢先申请（中国为申请在先原则，《商标法》第三十一条）；
   - T0 日期须登记进发布日历，并设置 T0+5 个月、T0+6 个月两次提醒。

## 六、检索与显著性风险评估

| 风险项 | 说明 | 等级 | 缓释措施 |
| --- | --- | --- | --- |
| 两字母短标近似密度高 | `JU` 在 9/42 类存在多件在先注册/申请（需实测检索） | 高 | 主推组合商标 + 图形；必要时加副标 |
| 呼叫近似 | `JU` / `Juju` / `Juju 笔记` 呼叫接近 | 中 | 不作为两件独立主标同时申请，避免自相冲突 |
| 描述性风险 | `JU` 本身非描述性，风险低 | 低 | — |
| 不良影响风险 | 见 §七 关于 `juju` 词义 | 中（仅备选名） | 备选名单独评估 |
| 海外在先权利 | Canonical 的 `Juju` 运维编排工具在软件类已有商标 | 高（仅备选名） | 见 §七 |

**必做检索**（申请前 2 周内完成，留档检索报告）：

1. CNIPA 商标网上检索（文字 `JU`、`JU 笔记`、`Juju`；类别 9 / 42 / 41 / 38；状态全量）；
2. WIPO Global Brand Database（马德里指定中国的在先国际注册）；
3. USPTO TESS / EUIPO eSearch（`JU`、`JU Notes`、`Juju`，Nice 9/42）；
4. 域名与社媒账号占位情况（`ju.app`、`junotes.*`、GitHub org）——非商标权但影响商业化。

## 七、备选方案 `Juju` 的风险提示（重要）

> 结论先行：**`Juju` 不建议作为主商标**，仅作为「`JU` 被驳回时的第二顺位」，且启用前必须完成检索与律师复核。

| # | 风险 | 具体说明 | 等级 |
| --- | --- | --- | --- |
| 1 | **在先商标冲突（最高危）** | Canonical（Ubuntu 背后的公司）自 2011 年起以 `Juju` 命名其服务编排工具，并在软件相关类别持有/使用该标识；在 9 / 42 类构成高度近似的在先权利，申请被驳回或异议的概率高 | 高 |
| 2 | **词义与「不良影响」风险** | `juju` 在英语中意指「物神 / 符咒」，带迷信色彩；部分审查辖区可能援引「不良影响」条款（中国《商标法》第十条第一款第（八）项）提出审查意见 | 中 |
| 3 | **显著性偏弱 / 通用化** | 该词在开源与音乐文化中已被大量使用，显著性被稀释，且难以阻止他人描述性使用 | 中 |
| 4 | **与本方主标 `JU` 的近似自冲突** | `Juju` 与 `JU` 呼叫近似，两件并行申请可能相互引证（审查意见互驳），且不利于品牌统一 | 中 |
| 5 | **域名与社媒已被占** | `juju.com` / `juju.app` 等优质域名已被他人持有，获客成本与混淆风险上升 | 中 |
| 6 | **与产品定位的语义错位** | 产品主张「本地优先、克制、可掌控」；`juju` 的符咒/魔法联想与定位不一致，品牌叙事成本高 | 低 |

**备选梯队建议**（按优先级）：

1. `JU` + 图形组合（主申请）；
2. `JU 笔记`（中文语境副标，与主标同族，冲突概率低于纯 `Juju`）；
3. `Juju`（仅英文市场、且必须先在 9/42 类完成 FTO 级检索与律师复核）；
4. 全新臆造词（如 `Juvia` / `Junode` 等需另做检索）作为兜底。

**启用阈值（Go / No-Go）**：只有当 ① CNIPA 与 USPTO/EUIPO 检索均无 9/42 类障碍，
② 律师出具「可注册性意见」，③ 与 Canonical 无实际混淆可能性认定时，方可启用 `Juju`。
