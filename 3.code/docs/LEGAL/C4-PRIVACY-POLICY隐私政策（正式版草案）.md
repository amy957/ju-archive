## 2. 处理原则

1. **本地优先（Local-first）**：默认不存在数据外发路径，产品功能不依赖任何远程服务。
2. **最小必要**：即使在你开启错误上报后，也只发送结构性字段（白名单固定，见 §3.2）。
3. **默认关闭**：错误上报默认关闭；缺省（`undefined`）与显式 `false` 均不发送任何数据。
4. **可验证**：所有事实性描述均可在源码（`src/core/errors.ts`）与 [`../PRIVACY.md`](../PRIVACY.md) 中核对。
5. **不画像**：不做用户画像、不做跨站追踪、不做自动化决策。

## 3. 处理的数据类型、来源与目的

### 3.1 仅存于本机的数据（不上传，永不离开设备）

| 数据类别 | 具体内容 | 存储位置 | 处理目的 | 法律依据 |
| --- | --- | --- | --- | --- |
| 内容数据 | 节点正文、标题、层级结构、标签、回收站、演示稿 | `localStorage`（键名 `juju.store.*`）/ 桌面 SQLite | 提供核心笔记功能 | 履行合同（GDPR Art. 6(1)(b)） |
| 附件与缓存 | 图片、大对象、索引缓存 | `IndexedDB` / 应用数据目录 | 提供核心功能与性能 | 履行合同 |
| 界面状态 | 当前文档、视图类型、面板宽度、折叠状态 | `localStorage` | 保持使用连续性 | 履行合同 / 正当利益（Art. 6(1)(f)） |
| 本地日志 | 环形错误日志（上限 **200 条**）、崩溃包 | 内存 / `%APPDATA%\JU\`（`crash_dumps/`） | 供**你本人**排查与导出 | 正当利益（本地诊断，不外发） |

> 加密模式（`ui.encrypted`）下，以上内容以 **AES-GCM** 密文落盘，密钥由你的口令派生且**仅保存在本机**。
> 我方**无法**解密你的数据——即使设备被我们取得。

### 3.2 可能离开设备的数据（仅在显式开启时）

| 场景 | 触发条件 | 发送内容（白名单） | 目的地 |
| --- | --- | --- | --- |
| 匿名错误上报 | 你手动开启「允许匿名错误上报」**且**产品配置了上报端点 | `msg` / `reason` / `stack` / `filename` / `lineno` / `name` / `ids`（最多 5 个节点 ID）/ `count` / `nodeCount` / `view` / `enc` / `ver` / `code`，外加 `kind` / `ts` / `ctx` | 【待填：上报端点域名】 |
| 更新检查 | 桌面版启动后（或手动检查） | 仅 `target` / `arch` / `current_version` 三元组（由更新端点 URL 承载） | 【待填：更新端点域名】 |

**明确排除（永不进入日志，也永不外发）**：

- 当前文档标识（`ui.currentDocId`）；
- 全部节点内容（`state.nodes` 及任何正文、标题、HTML、富文本）；
- `docId` / `currentDocId` / `nodes` / `text` / `content` 等字段（结构白名单直接丢弃）。

**脱敏**：发送前对 `msg` / `reason` / `stack` 统一脱敏——引号包裹的连续文本（≥4 字符）→ `"<redacted>"`，
手机号 → `<phone>`，邮箱 → `<email>`，IPv4 → `<ip>`；加密模式下 `msg` / `reason` / `stack` /
`filename` / `lineno` 一律替换为占位符，`ctx` 仅保留 `enc: true` 与版本号。

### 3.3 不收集的数据

- 不收集姓名、手机号、邮箱、身份证件、地理位置、通讯录、剪贴板历史；
- 不收集设备指纹（不做 Canvas/WebGL 指纹、不做设备 ID 持久标识）；
- 不收集使用行为埋点（无页面浏览、点击流、留存事件）；
- 不接入任何第三方分析、广告、推送、崩溃 SaaS（清单见 [`../PRIVACY.md`](../PRIVACY.md) §3 与 [`../SBOM.json`](../SBOM.json)）。

## 5. 数据保留期限（Retention）

> 原则：**本地数据由你掌控，我方不设「服务端保留」**；下表同时给出「默认值」与「可配置性」。

| 数据 | 默认保留期限 | 上限 / 清理机制 | 你可控的方式 |
| --- | --- | --- | --- |
| 节点内容、标签、结构 | **永久**（直至你删除） | 无自动过期 | 删除节点 / 清空回收站 / 清除站点数据 |
| 回收站内容 | **永久**（直至你清空） | 无自动过期 | 手动清空回收站 |
| 界面偏好（`localStorage`） | 永久（直至清除） | 无自动过期 | 清除站点数据 / 重置设置 |
| 附件与索引缓存（IndexedDB） | 永久（直至清除） | 无自动过期 | 清除站点数据 / 删除附件 |
| 内存环形错误日志（`window.__juLog`） | **仅当前会话**；条目上限 **200** | 超出即环形覆盖；关闭页面即释放 | 关闭/刷新页面 |
| 本地错误日志文件（桌面版） | **30 天**【待确认实现是否已具备轮转，若无则标注「保持至手动清理」】 | 建议上限 50 MB | 删除 `%APPDATA%\JU\logs` |
| 崩溃包（`crash_dumps/crash_<ts>.json`，M5-1b） | **90 天**【待实现轮转策略】 | 建议上限 200 个文件 / 100 MB | 删除 `%APPDATA%\JU\crash_dumps` |
| 自动备份快照（桌面版） | 【待填：保留份数，建议保留最近 5 份】 | 超出按最旧覆盖 | 删除备份目录 |
| 外发错误上报（服务端，若启用） | **90 天**（自接收起） | 到期自动删除，仅保留聚合计数 | 申请删除（见 §6） |
| 更新检查请求日志（服务端，若启用） | **30 天**，且**不落 IP 原文**（仅保留日级聚合） | 到期删除 | 不适用（不含个人数据） |

**保留期限的确定依据**：① 功能必要性（日志用于定位你主动反馈的问题）；
② 最小化（到期即删，不做无限累积）；③ 法定义务（如涉税务/诉讼保全则按法定期限延长，并在延长期间限制处理目的）。

## 6. 数据主体权利（GDPR 合规）

在 GDPR 及同类立法（如中国《个人信息保护法》、加州 CCPA/CPRA）下，你享有以下权利。
**由于本产品默认不向任何服务器传输内容数据，多数权利的行使方式是「在你自己的设备上操作」**，
这既可立即生效，也无需等待我方响应。

| --- | --- | --- | --- |

| 2 | **访问权** | Art. 15 | 全部数据在本机，直接查看；「反馈」面板可导出/复制本地日志 |
| 3 | **更正权** | Art. 16 | 直接编辑内容；界面偏好可在设置中修改 |
| 4 | **删除权（被遗忘权）** | Art. 17 | 删除节点→清空回收站；或清除站点数据 / 删除 `%APPDATA%\JU\`；外发数据可通过 §1 联系邮箱申请删除 |
| 5 | **限制处理权** | Art. 18 | 关闭错误上报即停止全部外发；离线使用即限制任何网络处理 |

| 10 | **投诉权** | Art. 77 | 可向所在地监管机构投诉（如你所在成员国的数据保护监管局）；亦可先联系 §1 的隐私联系人 |

1. 通过 §1 邮箱提交请求，说明请求类型与可用于定位的标识（若你从未开启上报，则我方无任何可定位数据，将直接书面告知「无数据」）；

**关于「删除」的重要说明**：因产品无账号、无服务端内容存储，
**你清除本机数据后即构成完整删除**——不存在需要另行申请删除的内容副本。

## 8. 安全措施

| 措施 | 说明 |
| --- | --- |
| 加密存储 | 可选 **AES-GCM**，密钥由口令派生（PBKDF2/scrypt 口径见实现），密钥仅存本机 |
| 传输安全 | 外发端点为 HTTPS；更新包使用签名校验（公钥内置，验签失败即拒绝安装） |
| 最小化采集 | 字段白名单 + 结构丢弃 + 文本脱敏三重收口 |
| 本地隔离 | 无账号体系，攻击面不包含「云端账号被撞库」这一路径 |
| 依赖可控 | 运行时零第三方依赖；构建期依赖经 [`../LICENSE-AUDIT.md`](../LICENSE-AUDIT.md) 审计 |
| 崩溃包 | 仅落本机 `app_data_dir/crash_dumps/`，不含节点正文与文档标识 |

**数据泄露通知**：若发生影响外发数据的安全事件，我方将在知悉后 **72 小时内**向监管机构通报，
并在风险较高时**不迟延地**通知受影响用户（GDPR Art. 33 / 34）。因本产品默认无服务端内容存储，
此类事件的潜在影响面在结构上被限定为「外发诊断数据」。

## 9. 未成年人保护

1. **产品定位**：JU 是面向成年专业人士与学生的**生产力工具**，不面向儿童设计，
   不含游戏化诱导、社交feed、虚拟道具或付费抽卡机制。
2. **年龄门槛**：
   - 欧盟（GDPR Art. 8）：信息服务同意年龄为 **16 岁**；成员国可下调但不低于 **13 岁**。
     未达该年龄者，需取得**监护人同意**方可开启任何外发功能（错误上报）；
   - 中国（《个人信息保护法》第 31 条）：处理**不满十四周岁**未成年人个人信息，
     须取得监护人同意，并制定**专门的个人信息处理规则**；
   - 美国（COPPA）：**13 岁以下**儿童，不进行任何定向收集——本产品**不收集**任何可识别个人身份的信息，
     因此不触发 COPPA 下的「实际知悉收集」义务。
3. **专门规则（不满 14 周岁）**：
   - **默认全本地**：所有内容仅存于本机，我方不接收任何儿童个人信息；
   - **外发功能禁止开启**：建议监护人保持「允许匿名错误上报」为**关闭**状态；
   - **不使用账号**：产品无注册流程，不存在儿童账号与儿童画像。
4. **监护人权利**：监护人可随时通过 §1 邮箱联系我们，要求确认是否存在相关外发数据；
   若存在（仅在你曾主动开启上报的前提下），我方将配合查阅与删除。
5. **若发现误收集**：一经确认，我方将在 **7 日内**删除相关外发数据并书面反馈。

## 10. Cookie 与追踪技术

JU **不使用** Cookie 做追踪，**不使用**指纹识别、像素标签、本地共享对象（LSO）或第三方脚本。
Web 版仅使用浏览器本地存储（`localStorage` / `IndexedDB`）保存你自己的数据与偏好，
这些存储**不用于识别你的网络行为**，也不与任何第三方共享。
