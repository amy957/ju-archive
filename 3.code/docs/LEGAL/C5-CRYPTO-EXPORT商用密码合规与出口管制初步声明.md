## 一、结论摘要（初步）

| 项目 | 初步结论 | 依据 / 说明 |
| --- | --- | --- |
| 密码类别 | **商用密码应用**（非核心密码、非普通密码） | 密码用于保护**用户本地数据**，不涉及国家秘密载体，不提供涉密通信 |
| 算法来源 | **仅使用平台原生 Web Crypto API**（浏览器 / WebView2 的 SubtleCrypto） | 无自研密码算法、无第三方密码库、无国密算法实现 |
| 对称加密 | **AES-GCM，256 位密钥** | `crypto.subtle.deriveKey({name:'AES-GCM', length:256})`、`crypto.subtle.encrypt/decrypt({name:'AES-GCM'})` |
| 密钥派生 | **PBKDF2-HMAC-SHA256，600,000 次迭代，16 字节随机盐** | `deriveKey()`；迭代数随密文载荷记录以兼容旧数据 |
| 随机数 | **`crypto.getRandomValues`**（盐 16B / IV 12B） | 不自行实现 PRNG |
| 密钥管理 | 口令派生、密钥仅驻留内存、`extractable:false`、**不上传、不托管、不备份到服务端** | 无密钥分发 / 密钥托管 / 密钥恢复服务 |
| 网络行为 | **无云端同步、无账号体系**；加密对象为本地存储（localStorage / SQLite）静态数据 | 与 F5「本地优先」一致 |
| 是否属「涉及国家安全、国计民生、社会公共利益的商用密码产品」 | **初步判断：不属于**；本产品是通用效率软件的**内置本地加密功能**，不是以密码功能为核心的专用密码产品 | 最终定性需主管部门 / 检测机构确认（见 §四 待办） |
| 出口管制 | 使用**公开标准算法**、密钥本地生成、无密码通信功能，通常不构成管制清单中的「密码设备」；但密码物项敏感，**出口前必须按最新清单逐项核对** | 见 §五 自查表 |

**一句话声明（可用于对外材料，需法务复核后定稿）**：

> 本软件仅调用操作系统 / 浏览器原生的 Web Crypto API 提供 AES-GCM 256 位加密，
> 密钥由用户口令经 PBKDF2-SHA256 在本机派生且仅存于内存；软件**不使用任何自研密码算法**，
> 不提供密钥托管、密钥分发或加密通信服务，数据默认不出本机。
> 本软件属于通用软件的常规密码应用，初步判断不属于「涉及国家安全、国计民生、
> 社会公共利益的商用密码产品」；如用于商业分发，将按属地要求完成商用密码备案 / 检测（如适用）。

## 二、密码使用事实清单（可核验）

| 编号 | 事实 | 代码证据（函数） | 备注 |
| --- | --- | --- | --- |
| K1 | 对称算法为 AES-GCM，密钥长度 256 | `deriveKey()`（`{ name:'AES-GCM', length:256 }`） | 由 Web Crypto 实现，无自研 S 盒 / 轮函数 |
| K2 | 每次加密生成 12 字节随机 IV | `encryptState()`（`getRandomValues(new Uint8Array(12))`） | IV 随密文载荷保存，不复用 |
| K3 | 口令派生使用 PBKDF2-SHA256，600,000 次迭代 | `ENC_ITER = 600000`、`deriveKey()` | 旧密文按 `payload.iter` 兼容解密 |
| K4 | 盐为 16 字节随机值，同一口令会话内复用、换口令即重建 | `_getOrCreateSalt()` | 盐随载荷保存，不作密钥 |
| K5 | 派生密钥不可导出（`extractable:false`） | `deriveKey()` 第 4 参数 | 降低内存抓取后的密钥外带风险 |
| K6 | 明文只在本机内存中出现；密文写入 localStorage 或桌面 SQLite | `encryptState()` / `writeEncryptedStore()` | 无网络上传路径 |
| K7 | 无自研密码算法 / 无第三方密码库 | 全仓检索 `crypto.subtle` 调用点 | 仅标准 API |
| K8 | 无密钥托管 / 恢复服务；忘记口令即无法解密（产品明示） | `promptUnlock()` / 重置流程 | 属于产品设计而非合规豁免 |
| K9 | 加密载荷结构：`{v, salt, iv, cipher, iter, updatedAt}` | `EncPayload` | 不含任何密钥材料 |

> 复核方式：以函数名定位，不依赖行号；`crypto.ts` 为唯一加密适配层，
> 业务模块不得直接调用 `crypto.subtle`（新增调用需在本表登记并复核）。

## 三、法律框架对照（中国）

> 以下仅列**适用框架与判断路径**，不逐条引用条文编号，避免版本差异造成误引；
> 正式意见由法务按现行有效文本出具。

### 3.1 《中华人民共和国密码法》

- 密码分为**核心密码、普通密码、商用密码**；核心 / 普通密码用于保护国家秘密，
  商用密码用于保护**不属于国家秘密**的信息。
- 本产品不承载国家秘密，加密对象为终端用户自有笔记 / 日历 / 表格数据，
  故按**商用密码应用**管理，不适用核心 / 普通密码的行政审批路径。
- 商用密码的科研、生产、销售、服务、进出口等环节实行**许可 / 检测认证 / 备案**等分类管理
  （具体适用范围以《商用密码管理条例》及配套目录为准）。

### 3.2 《商用密码管理条例》（2023 年修订）

| 环节 | 本产品情形 | 初步判断 | 待确认 |
| --- | --- | --- | --- |
| 商用密码产品检测认证 | 软件内置标准算法加密功能，非专用密码产品 | 一般不触发**强制**认证；如以「商用密码产品」名义销售，需按目录判断 | 是否落入《网络关键设备和网络安全专用产品目录》 |
| 商用密码服务 | 不提供加密外包、密钥托管、电子认证等服务 | 不属于商用密码服务 | — |
| 商用密码应用安全性评估（密评） | 面向普通消费者 / 中小企业本地软件 | 通常不强制；若进入关基 / 政务场景，按业主要求执行 | 客户行业与部署形态 |
| 备案 | 商用分发时可能需向**属地省级密码管理局**备案 | **待办**（见 §四） | 销售主体注册地、分发渠道 |

### 3.3 出口管制

- 适用框架：《出口管制法》《对外贸易法》及**两用物项出口管制清单**（商务部 / 海关总署发布，动态调整）。
- 密码物项在清单中通常按「信息安全产品 / 密码设备」描述，关注点包括：
  ①是否实现**保密通信**；②是否具备**密钥托管 / 恢复**；③算法是否公开标准；
  ④是否为民用通用软件的内置安全功能。
- 本产品特征：标准算法、密钥本地生成且不可导出、无通信加密、无密钥托管 ——
  与「专用密码设备」存在实质差异，**初步判断不落入典型管制条目**；
  但**清单会更新**，出口（含应用商店跨境分发、境外客户交付）前必须逐项复核，
  必要时申请许可或取得分类意见。

### 3.4 与个人信息保护 / 数据安全的交叉

- 加密是《个人信息保护法》《数据安全法》下的**安全保护措施**，不是豁免义务的理由；
- 隐私政策需如实披露：加密为**可选功能**、密钥由用户口令派生、**无法找回**、
  数据默认本地存储（见 [`C4-PRIVACY-POLICY.md`](./C4-PRIVACY-POLICY.md)）。

## 五、出口管制自查表（每次出口前填写）

| 自查项 | 本产品情况 | 结论 |
| --- | --- | --- |
| 是否实现保密通信（网络传输加密）？ | 否（仅本地静态数据加密） | 降低管制风险 |
| 是否提供密钥托管 / 密钥恢复？ | 否 | 降低管制风险 |
| 是否使用非公开 / 自研算法？ | 否（AES-GCM / PBKDF2-SHA256 均为公开标准） | 降低管制风险 |
| 是否为民用通用软件的内置功能？ | 是（笔记 / 日历 / 表格效率工具） | 降低管制风险 |
| 是否落入最新两用物项清单具体条目？ | **待逐项核对**（清单动态更新） | **出口前必须确认** |
| 是否需要出口许可 / 分类意见？ | 视目的地与清单核对结果 | **待法务确认** |
